Why Kids Should Not Add the Bottom Numbers in Fractions

Name the size of each piece

The child looks at a bar divided into eight equal parts. Every piece is an eighth, so the denominator describes a fixed piece size.

Shade the first amount

Two eighths are shaded first. The child can see the numerator as the number of selected pieces and the denominator as the name of those pieces.

Add more pieces of the same size

Three more eighths are shaded. The pieces have not become smaller and the whole has not been divided again, so the denominator stays eight.

Count and explain

Five eighths are now shaded. The child writes the sum and explains why only the numerator changed: more pieces were counted, but every piece remained an eighth.

When fractions have the same denominator, children need to count how many equal pieces are shaded. The size of every piece stays the same, so the denominator does not change.

The denominator names the size of the pieces

In a fraction, the denominator tells how many equal parts make one whole. Eighths are parts created when one whole is split into eight equal pieces. In 2/8 + 3/8, both fractions use the same-sized pieces. Adding them means counting two eighths and three eighths together, which makes five eighths.

The denominator stays eight because the size of each piece has not changed. A common error is writing 5/16 by adding both numbers. A picture exposes the problem immediately: the original whole has not been cut into sixteen pieces. It is still cut into eight. The child has shaded more of the same kind of piece, not created a new kind of piece.

Fraction bars, circles, strips of folded paper, or food models can help as long as the pieces are equal. Always ask what one piece is called before asking for the sum.

Let the child shade and name the parts

Draw one long rectangle and divide it into equal sections. Shade the first fraction in one color and the second fraction in another color. Count the shaded sections together. Then ask the child to finish the sentence: “There are ___ shaded pieces, and each piece is an ___.” The answer gives the numerator and denominator naturally.

Try a second example with a different denominator, such as fifths or sixths. The child should notice that the rule is not “keep the bottom number because a teacher said so.” The denominator stays because it names the piece size that both fractions already share.

Pause before simplifying

After the sum is found, a fraction may sometimes be simplified, but that is a separate idea. First make sure the child can correctly add like denominators. Then use a model to see whether the shaded amount can be named with larger pieces. Keeping these steps separate prevents confusion.

Ask the child to check the reasonableness of the answer. Two eighths plus three eighths is less than one whole, so five eighths makes sense. An answer such as five sixteenths would show a smaller amount than either model suggests.
