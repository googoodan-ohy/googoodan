How to Help a Child With 2 Digit Subtraction With Regrouping

Notice the ones are not enough

The child sees that two ones cannot be used to take away eight ones. This pause is useful because it identifies exactly why an exchange is needed.

Trade one ten

One tens rod is exchanged for ten single units. The total value stays the same even though the number is now organized as three tens and twelve ones.

Take away from the regrouped amount

The child removes eight from twelve ones and then subtracts the tens. The crossed-out digits on paper now record a real place-value action rather than a mysterious borrowing rule.

Check with addition

The child adds the difference to the amount that was taken away. Returning to the starting number confirms that the exchange and subtraction were consistent.

Subtraction with regrouping is not simply “borrowing.” It is a place-value exchange. When children see one ten become ten ones, the written marks begin to make sense.

A ten can be renamed, but its value stays the same

The number 42 is four tens and two ones. It can also be three tens and twelve ones because one of the tens can be exchanged for ten ones. The total value has not changed. Only the way it is organized has changed. This is the key idea that written regrouping must represent.

Build 42 with four tens rods and two cubes. Ask the child to take away eight ones. The child will see that there are not enough individual cubes. Trade one rod for ten cubes, then count twelve cubes. Now removing eight leaves four ones. Three tens remain, so the difference is thirty-four. The crossing-out and tiny digits on paper are a quick record of that exchange.

Use the word trade or regroup when you can. Those words remind the child that nothing is created and nothing disappears. One ten has simply changed form.

Guide the child from blocks to paper

Begin with an equation that needs only one exchange. Let the child build the first number, name the tens and ones, and decide why a trade is needed. After the cubes show the solution, draw the same tens rods and ones dots. Only then write the vertical subtraction problem.

Ask the child to point to each changed digit and explain it. “This 3 means three tens. This 12 means twelve ones.” Speaking about the value prevents a child from treating the crossed-out digits as random symbols.

Check by putting the parts back together

Subtraction can be checked with addition. After finding the difference, add it to the number that was taken away. If the result returns to the starting number, the answer is consistent. In 42 − 18 = 24, adding 24 and 18 should make 42.

If an answer feels impossible, estimate first. A number near forty minus a number near twenty should be near twenty. Estimation will not give the exact answer, but it often reveals a misplaced digit or forgotten exchange.
