Compléter les étapes du calcul posé

Additionner trois nombres décimaux

Cette activité porte sur l’addition de trois nombres décimaux. L’enfant s’entraîne à compléter les étapes du calcul posé. Il additionne les chiffres des unités, des dixièmes et des centièmes entre eux. Si les nombres n’ont pas le même nombre de chiffres après la virgule, il écrit des zéros dans les cases vides pour aligner les chiffres selon leur valeur de position.

Déroulement de la séance

  1. Additionner les chiffres des unités, des dixièmes et des centièmes entre eux. Si les nombres n’ont pas le même nombre de chiffres après la virgule, écrire des zéros dans les cases vides pour aligner les chiffres selon leur valeur de position.
  2. Repérer le rang où se trouve la case vide. Additionner les chiffres de même rang, tenir compte des retenues, puis vérifier le calcul avec le chiffre inscrit.

Exemples corrigés

Écris le nombre qui convient dans la case □ de cette opération posée. 1,20 0,34 + 2,50 ────── 4,□4

  1. Écrire 1,2 et 2,5 sous la forme 1,20 et 2,50, puis aligner les virgules des trois nombres.
  2. La somme des centièmes est 0 + 4 + 0 = 4.
  3. La somme des dixièmes est 2 + 3 + 5 = 10. Écrire 0 à ce rang et reporter 1 aux unités.
  4. Pour les unités, ajouter aussi la retenue : 1 + 0 + 2 + 1 = 4. Écrire 0 dans □ pour obtenir la somme 4,04, puis la comparer à la valeur de l’expression initiale.

Erreurs fréquentes et pistes d’aide

Aligner les chiffres par la droite au lieu d’aligner les virgules, ou oublier une retenue

Tracer une ligne verticale au niveau des virgules et vérifier que les chiffres de même unité ont bien été additionnés. Si la somme d’un rang, retenue comprise, est supérieure ou égale à 10, écrire le chiffre des unités de la somme et reporter le chiffre des dizaines au rang immédiatement à gauche.

Regarder seulement la réponse et passer l’explication du calcul

Repérer le rang où se trouve la case vide. Additionner les chiffres de même rang, tenir compte des retenues, puis vérifier le calcul avec le chiffre inscrit.

Questions pour vérifier la compréhension

  • Dans ce calcul 1,2+0,34+2,5, peux-tu dire quelle unité représente chaque chiffre ?
  • Peux-tu vérifier d’une autre manière que le résultat obtenu est correct ?
  • Quand tu complètes les étapes du calcul posé, que dois-tu vérifier d’abord : les signes opératoires ou les unités de chaque rang ? Peux-tu expliquer pourquoi ?

Utiliser et corriger la fiche

Commencez par lire ensemble 3 à 5 exercices, puis laissez l’enfant résoudre les autres. Pour les erreurs dans les cases à compléter, réexpliquez comment additionner les chiffres de même rang dans trois nombres décimaux, puis vérifiez un seul nouvel exercice en changeant les nombres. Observez si les mêmes erreurs se répètent plutôt que de vous concentrer sur la vitesse.

Pour aller plus loin

  • Dans l’opération posée de l’exemple, complétez de nouveau la case vide de la somme 4,□4, puis appliquez la méthode à deux nouveaux exercices dans les mêmes conditions.
  • Reprenez seulement les étapes qui ont posé problème pour compléter les étapes du calcul posé. Si la lecture des nombres est difficile, utilisez un tableau de numération ; si le calcul est difficile, cherchez à distinguer la difficulté en reprenant les calculs sur les nombres entiers naturels.
