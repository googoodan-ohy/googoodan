Préparer le calcul à l’aide du tableau de numération

Placer la virgule dans le quotient

Cette activité porte sur « Placer la virgule dans le quotient ». Vous vous entraînez à préparer le calcul à l’aide du tableau de numération. Multipliez les deux nombres par le même multiple de 10 afin que le diviseur soit un nombre entier naturel. Si le diviseur est déjà un nombre entier naturel, gardez la virgule à la même place pour effectuer la division.

Déroulement de la séance

  1. Multipliez les deux nombres par le même multiple de 10 afin que le diviseur soit un nombre entier naturel. Si le diviseur est déjà un nombre entier naturel, gardez la virgule à la même place pour effectuer la division.
  2. Lisez d’abord les en-têtes des colonnes, puis placez chaque chiffre dans la colonne correspondant à sa valeur de position. Pour les colonnes sans valeur, distinguez le 0 et la case vide selon la consigne de l’exercice.

Exemples corrigés

Calcule la division suivante et écris le résultat dans le tableau de numération en respectant la valeur de position : 0.9 ÷ 5

  1. Le diviseur 5 est déjà un nombre entier naturel : calculez 0.9 ÷ 5.
  2. 0.9 ÷ 5 = 0.18 ; le quotient de l’égalité de départ est donc aussi 0.18.
  3. Vérifiez avec une multiplication : 0.18 × 5 = 0.9.
  4. Dans le tableau de numération, écrivez 0 dans la colonne des unités, 1 dans celle des dixièmes et 8 dans celle des centièmes.

Erreurs fréquentes et pistes d’aide

Multiplier par 10 le diviseur seul, ou omettre le 0 dans le quotient

Indiquez si les deux nombres ont été multipliés par le même facteur. Si le diviseur ne peut pas être placé une seule fois dans une unité de numération donnée, écrivez 0 à la place correspondante dans le quotient.

Regarder seulement la réponse et passer le raisonnement

Lisez d’abord les en-têtes des colonnes, puis placez chaque chiffre dans la colonne correspondant à sa valeur de position. Pour les colonnes sans valeur, distinguez le 0 et la case vide selon la consigne de l’exercice.

Questions pour vérifier la compréhension

  • Dans 0.9 ÷ 5, peux-tu dire quelle unité représente chacun des nombres ?
  • Peux-tu vérifier autrement que le résultat que tu as trouvé est correct ?
  • Dans « Préparer le calcul à l’aide du tableau de numération », que faut-il regarder d’abord : le signe de l’opération ou l’unité de chaque colonne ? Pourquoi ?

Utiliser et corriger la fiche

Au début, lisez ensemble 3 à 5 exercices, puis laissez votre enfant faire les autres. Pour une erreur dans « Préparer le calcul à l’aide du tableau de numération », réexpliquez le placement de la virgule dans le quotient, puis vérifiez la compréhension avec un seul exercice aux nombres différents. Observez si la même erreur se répète plutôt que de privilégier la rapidité.

Pour aller plus loin

  • Cachez la réponse et calculez de nouveau 0.9 ÷ 5, puis appliquez la même démarche à deux nouveaux exercices de même type.
  • Reprenez uniquement les étapes de « Préparer le calcul à l’aide du tableau de numération » qui posent problème à expliquer. Si la lecture des nombres est difficile, revoyez le tableau de numération ; si le calcul est difficile, cherchez si la difficulté vient des calculs sur les nombres entiers naturels.
