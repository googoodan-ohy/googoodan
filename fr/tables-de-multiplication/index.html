Comment utiliser cette page

Cette page s’adresse aux élèves du CP au CM2, aux parents et aux enseignants. Choisissez les tables à travailler, puis imprimez la fiche d’exercices et son corrigé, chacun sur une feuille A4.

« Nouveaux nombres » change l’ordre des calculs : la même table peut être refaite plusieurs fois. Pour enregistrer en PDF, choisissez « Enregistrer au format PDF » dans la fenêtre d’impression.

Pour mieux retenir les tables

  • Travaillez une seule table à la fois, quelques minutes par jour.
  • L’ordre des facteurs ne change pas le résultat : 3 × 7 = 7 × 3.
  • La table de 4, c’est le double de la table de 2 ; pour la table de 9, on enlève une fois le nombre à la table de 10.
  • Vérifiez avec le tableau, puis entraînez-vous sur la fiche sans les réponses.

Exemples de multiplication

  • 3 × 7 = 21 : 3 groupes de 7 font 21.
  • 9 × 6 = 60 − 6 = 54 : on retire un 6 à la table de 10.
  • 0 × 8 = 0 : zéro fois 8 donne toujours zéro.

Erreurs fréquentes

  • Multiplier, ce n’est pas additionner les deux facteurs : 3 × 7 vaut 21, pas 10.
  • Dans la table de 0, tous les résultats valent 0 ; dans celle de 1, le résultat reste le même nombre.
  • Dans la table de 9, la somme des chiffres du résultat est un multiple de 9 : 54 donne 9 et 99 donne 18.
