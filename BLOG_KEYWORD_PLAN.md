# English blog keyword plan

## Operating rule

- Each article owns one distinct US search intent and one primary keyword cluster.
- Before publishing, check this table and link to the matching printable worksheet.
- Broad hub terms belong to existing landing pages; blog posts support those pages with child-centered problem-solving stories.
- Do not publish another article with the same primary intent unless it serves a clearly different grade, mistake pattern, or worksheet format.
