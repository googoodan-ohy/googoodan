3er-Reihe üben und ausdrucken

So funktioniert es

Teile drei Gruppen in zwei Gruppen und eine weitere: 3 · n = 2 · n + n. So nutzt du die bekannte Verdopplung.

Beispiel

3 · 8 = 16 + 8 = 24.

Häufiger Fehler

Das Doppelte zählt erst zwei Gruppen. Eine weitere Achtergruppe fehlt noch.
