Einen fehlerhaften Divisionsweg korrigieren

Dezimalzahl mit zwei Nachkommastellen ÷ natürliche Zahl – Division geht an der vorgegebenen Stelle ohne Rest auf

Mit der Aufgabe „Einen fehlerhaften Divisionsweg korrigieren“ üben Sie das Dividieren einer Dezimalzahl durch eine natürliche Zahl. Da der Divisor bereits eine natürliche Zahl ist, werden die Dezimalkommas nicht verschoben. Setzen Sie das Komma im Quotienten direkt über das Komma im Dividenden und rechnen Sie von links nach rechts. Die 0 an der Zehntelstelle bleibt auch beim Teilen durch 3 eine 0, deshalb schreiben Sie auch im Quotienten eine 0. Teilen Sie die 9 Hundertstel durch 3, erhalten Sie 3 Hundertstel. Der Quotient ist 2,03.

Das sollten Sie zuerst prüfen

  • Die Einheiten der Zehntel, Hundertstel und Tausendstel kennen
  • Zahlen mit gleichem Stellenwert unterscheiden und die Grundrechenarten mit natürlichen Zahlen beherrschen

So gehen Sie beim Erklären vor

  1. Da der Divisor bereits eine natürliche Zahl ist, werden die Dezimalkommas nicht verschoben. Setzen Sie das Komma im Quotienten direkt über das Komma im Dividenden und rechnen Sie von links nach rechts.
  2. Bei 6,09÷3 teilen Sie 6 durch 3 und schreiben die 2 an die Einerstelle.
  3. Die 0 an der Zehntelstelle bleibt auch beim Teilen durch 3 eine 0, deshalb schreiben Sie auch im Quotienten eine 0. Teilen Sie die 9 Hundertstel durch 3, erhalten Sie 3 Hundertstel. Der Quotient ist 2,03.
  4. Streichen Sie die falsche Antwort nicht gleich durch, sondern markieren Sie die erste Stelle, an der der Rechenweg abweicht. Schreiben Sie rechts im freien Feld ab dieser Stelle den richtigen Rechenweg auf und überprüfen Sie ihn mit der ursprünglichen Aufgabe.

Häufige Fehler und passende Hilfen

Das Komma im Dividenden verschieben, obwohl der Divisor eine natürliche Zahl ist

Der Divisor ist bereits eine natürliche Zahl, daher müssen Sie die Einheiten nicht ändern. Lassen Sie vom Komma im Dividenden eine Linie nach oben ziehen, damit das Komma im Quotienten direkt darüber steht.

Die 0 an der Zehntelstelle des Quotienten weglassen und 2,03 als 2,3 schreiben

Die 0 an der Zehntelstelle zeigt in der Stellenwerttafel, dass der Quotient keine Zehntel enthält. Wenn Sie die 0 weglassen, werden die 3 Hundertstel zu 3 Zehnteln und der Wert ändert sich.

Arbeitsblatt nutzen und nachbesprechen

Lesen Sie anfangs 3~5 Aufgaben gemeinsam, die übrigen löst das Kind. Bei Fehlern in „Einen fehlerhaften Divisionsweg korrigieren“ erklären Sie die Einheiten von „Dezimalzahl mit zwei Nachkommastellen ÷ natürliche Zahl – Division geht an der vorgegebenen Stelle ohne Rest auf“ noch einmal und überprüfen anschließend nur eine Aufgabe mit anderen Zahlen. Achten Sie darauf, ob derselbe Fehler wiederholt auftritt, nicht auf das Tempo.

Nächste Übungen

  • Überprüfen Sie die 0 in der Mitte des Quotienten mithilfe der Stellenwerttafel und kontrollieren Sie das Ergebnis durch Multiplikation mit dem Divisor.
  • Wenn das Kind Aufgaben lösen kann, bei denen die Division an der Hundertstelstelle ohne Rest aufgeht, üben Sie gesondert Aufgaben, bei denen ein Rest in kleinere Einheiten umgewandelt wird.
