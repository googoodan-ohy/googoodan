Leitfaden zum Unterrichten

Einen fehlerhaften Divisionsweg korrigieren

Natürliche Zahl ÷ natürliche Zahl – den Quotienten als Dezimalzahl schreiben

Bei dieser Aufgabe schreiben Sie den Quotienten von 3÷4 als Dezimalzahl. Die Einerstelle des Quotienten ist 0. Schreiben Sie den Dividenden 3 zunächst als 3,00. Setzen Sie dann das Komma im Quotienten direkt über das Komma im Dividenden und rechnen Sie weiter.

Das sollten Sie zuerst prüfen

  • Die Einheiten der Zehntel, Hundertstel und Tausendstel kennen
  • Zahlen mit gleichem Stellenwert unterscheiden und die Grundrechenarten mit natürlichen Zahlen beherrschen

So gehen Sie beim Erklären vor

  1. Bei 3÷4 ist 3 kleiner als 4. Deshalb schreiben Sie eine 0 an die Einerstelle des Quotienten.
  2. Schreiben Sie die natürliche Zahl 3 als 3,00, ohne ihren Wert zu verändern. Setzen Sie nun das Komma im Quotienten direkt über das Komma im Dividenden.
  3. Holen Sie bis zur Zehntelstelle herunter. Wenn Sie 30 Zehntel durch 4 teilen, erhalten Sie im Quotienten 7 und 2 Zehntel als Rest.
  4. Holen Sie die 0 an der Hundertstelstelle herunter und wandeln Sie den Rest in 20 Hundertstel um. 20÷4=5, deshalb ist der Quotient 0,75.
  5. Streichen Sie die falsche Antwort nicht gleich durch, sondern markieren Sie die erste Stelle, an der der Rechenweg abweicht. Schreiben Sie rechts im freien Feld ab dieser Stelle den richtigen Rechenweg auf und überprüfen Sie ihn mit der ursprünglichen Aufgabe.

Beispiele mit Lösungsweg

Im falschen schriftlichen Rechenweg wurde der Quotient von 3÷4 als 7,5 angegeben. Finde den Fehler und korrigiere ihn.

  1. Bei 3÷4 ist 3 kleiner als 4. Deshalb schreiben Sie eine 0 an die Einerstelle des Quotienten.
  2. Schreiben Sie die natürliche Zahl 3 als 3,00, ohne ihren Wert zu verändern. Setzen Sie nun das Komma im Quotienten direkt über das Komma im Dividenden.
  3. Holen Sie bis zur Zehntelstelle herunter. Wenn Sie 30 Zehntel durch 4 teilen, erhalten Sie im Quotienten 7 und 2 Zehntel als Rest.
  4. Holen Sie die 0 an der Hundertstelstelle herunter und wandeln Sie den Rest in 20 Hundertstel um. 20÷4=5, deshalb ist der Quotient 0,75.
  5. Kontrollieren Sie das Ergebnis mit 0,75×4=3.

Häufige Fehler und passende Hilfen

Das Komma im Dividenden verschieben, obwohl der Divisor eine natürliche Zahl ist

Der Divisor ist bereits eine natürliche Zahl, daher müssen Sie die Einheiten nicht ändern. Lassen Sie vom Komma im Dividenden eine Linie nach oben ziehen, damit das Komma im Quotienten direkt darüber steht.

Annehmen, dass sich kein Quotient berechnen lässt, weil 3 kleiner als 4 ist

Der ganzzahlige Anteil des Quotienten ist 0, aber die übrigen 3 lassen sich in kleinere Einheiten umwandeln. Schreiben Sie zuerst 3,00 und setzen Sie dann das Komma im Quotienten an die passende Stelle, um weiterzurechnen.

Fragen zum Verständnis

  • Kannst du bei 3÷4 prüfen, ob der Divisor schon eine natürliche Zahl ist?
  • Über welcher Stelle im Dividenden muss das Komma im Quotienten stehen?
  • Warum schreibst du eine 0 an die Einerstelle des Quotienten, wenn 4 größer als 3 ist?

Arbeitsblatt nutzen und nachbesprechen

Lesen Sie anfangs 3~5 Aufgaben gemeinsam, die übrigen löst das Kind. Bei Fehlern in „Einen fehlerhaften Divisionsweg korrigieren“ erklären Sie die Einheiten von „Natürliche Zahl ÷ natürliche Zahl – den Quotienten als Dezimalzahl schreiben“ noch einmal und überprüfen anschließend nur eine Aufgabe mit anderen Zahlen. Achten Sie darauf, ob derselbe Fehler wiederholt auftritt, nicht auf das Tempo.

Nächste Übungen

  • Kontrollieren Sie durch Multiplikation des Quotienten mit dem Divisor, ob Sie wieder die ursprüngliche Zahl erhalten.
  • Wenn das Kind das Komma an der richtigen Stelle beibehält, lösen Sie Aufgaben, bei denen die Division an der vorgegebenen Stelle ohne Rest aufgeht, und Aufgaben, bei denen am Ende eine 0 heruntergeholt werden muss, im Wechsel.
