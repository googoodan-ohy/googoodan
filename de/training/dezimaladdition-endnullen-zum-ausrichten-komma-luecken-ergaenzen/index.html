Leitfaden zum Unterrichten

Setze das Dezimalkomma und ergänze fehlende Stellen.

Zum Angleichen der Stellenzahl eine 0 an die Dezimalzahl anhängen

In dieser Übung geht es darum, zum Angleichen der Stellenzahl eine 0 an die Dezimalzahl anzuhängen. Geübt wird dies mit der Methode „Setze das Dezimalkomma und ergänze fehlende Stellen.“ Schreiben Sie in die Lücke am Ende einer Dezimalzahl mit einer Nachkommastelle eine 0, damit die Zahl zwei Nachkommastellen hat. Wenn Sie hinten an eine Dezimalzahl eine 0 anhängen, verändert sich ihr Wert nicht.

Das sollten Sie zuerst prüfen

  • Die Einheiten der ersten, zweiten und dritten Nachkommastelle kennen
  • Zahlen mit gleichem Stellenwert unterscheiden und grundlegende Rechenoperationen mit natürlichen Zahlen ausführen

So gehen Sie beim Erklären vor

  1. Suchen Sie Dezimalzahlen mit einer und mit zwei Nachkommastellen. Schreiben Sie in die Lücke am Ende der Dezimalzahl mit einer Nachkommastelle eine 0, damit beide Zahlen zwei Nachkommastellen haben.
  2. Erklären Sie zunächst eine Aufgabe in Worten und lösen Sie die nächste nach derselben Methode.

Beispiele mit Lösungsweg

2.4+0.37 → 2.4[ ]+0.37. Welche Ziffer kommt hinten in die Lücke?

  1. Wenn Sie an eine Dezimalzahl mit einer Nachkommastelle hinten eine 0 anhängen, verändert sich ihr Wert nicht.
  2. Schreiben Sie 2.4 als 2.40. So hat die Zahl genauso viele Nachkommastellen wie 0.37.
  3. Lassen Sie die 4 an der ersten Nachkommastelle stehen und schreiben Sie eine 0 an die zweite Nachkommastelle.
  4. Da 2.40 und 2.4 gleich groß sind, gilt 2.40−2.4=0. In die Lücke kommt die Ziffer 0.

Häufige Fehler und passende Hilfen

Die 0 an einer anderen Stelle als hinten an die Dezimalzahl anhängen und dadurch ihren Wert verändern

Lassen Sie die vorhandenen Ziffern an ihrer Stelle und schreiben Sie in die Lücke am Ende eine 0. Schreiben Sie 2.4 als 2.40. Als 2.04 geschrieben hätte die Zahl einen anderen Wert.

Nur auf die Lösung schauen und die Begründung überspringen

Erklären Sie zunächst eine Aufgabe in Worten und lösen Sie die nächste nach derselben Methode.

Fragen zum Verständnis

  • Kannst du mir sagen, für welche Einheiten die einzelnen Ziffern in 2.4+0.37 stehen?
  • Warum kannst du sagen, dass die Zahl gleich groß bleibt, wenn du hinten an 2.4 eine 0 anhängst?
  • Was solltest du bei „Setze das Dezimalkomma und ergänze fehlende Stellen.“ zuerst prüfen: das Rechenzeichen oder die Einheit der Stelle? Begründe deine Antwort.

Arbeitsblatt nutzen und nachbesprechen

Lesen Sie zunächst 3–5 Aufgaben gemeinsam durch, die übrigen löst das Kind selbst. Erklären Sie bei Fehlern bei „Setze das Dezimalkomma und ergänze fehlende Stellen.“ noch einmal, dass sich der Wert nicht ändert, wenn man hinten an eine Dezimalzahl eine 0 anhängt. Ändern Sie dann die Zahlen und lassen Sie eine Aufgabe zur Kontrolle rechnen. Achten Sie darauf, ob sich derselbe Fehler wiederholt, statt auf das Tempo zu schauen.

Nächste Übungen

  • Füllen Sie die Lücke in der Beispielaufgabe 2.4[ ]+0.37 erneut aus und wenden Sie das Vorgehen auf zwei neue Aufgaben mit denselben Voraussetzungen an.
  • Üben Sie bei „Setze das Dezimalkomma und ergänze fehlende Stellen.“ noch einmal den Schritt, bei dem die Erklärung ins Stocken gerät. Falls das Lesen der Zahlen schwerfällt, nutzen Sie die Stellenwerttafel. Falls das Rechnen schwerfällt, klären Sie die Ursache mit einer Rechnung mit natürlichen Zahlen.
