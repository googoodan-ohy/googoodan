指導ガイド

筆算で計算する

0を含む数のくり下がり

同じ位どうしを引き、必要なときは左の位の1つ分を10個に分けて表す考え方を身につけます。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたのひき算とたし算

指導の進め方

  1. 一の位を基準にして、2つの数の位をそろえます。一の位から左へ1つずつ計算し、位の値やくり下がりについて説明させます。
  2. ひかれる数とひく数の同じ位の数字をそろえます。
  3. 一の位から引きます。上の数字が小さいときは、左にある最も近い0でない位から1をくり下げ、間の0を9にします。計算する位の数に10をたします。
  4. くり下げた位の数字も1小さくなったか確かめます。また、差にひく数をたして、もとの数になるか確かめます。

例題と解き方

703 − 268を計算しましょう。

  1. 一の位の3から8を引けず、十の位も0なので、百の位から1をくり下げて十の位を10にします。そのうち1を一の位にくり下げると、百の位の数字は6、十の位の数字は9、一の位の数は13になります。
  2. 一の位：13−8=5。
  3. 十の位：9−6=3。
  4. 百の位：6−2=4。
  5. 差は435です。435+268=703となることを確かめます。
例題の答えを見る435

よくある間違いと教え方

くり下げたあと、左の位の数字をそのままにします。

0のある位をまたいでくり下げると、間の位が9になることを、位取りブロックを使って確かめましょう。

数字の左端をそろえて、異なる位どうしを計算します。

同じ位どうしが縦にそろっているか、まず確かめましょう。

理解度を確かめる質問

  • 左の位から1つ分を持ってくると、その位はどう変わるかな？
  • 一の位の3から8は引けないね。十の位が0のとき、どこからくり下げる？
  • 703は百が7つ、十が0、一が3つ。268はそれぞれいくつかな？

プリントの活用と丸つけ後の指導

まず、例の答え435になる理由を子どもが説明できるか確かめます。残った部分と引いた部分を合わせると、もとの数になるかに注目します。最初の2問は解き方を説明させ、そのあとの3問は一人で解かせます。同じ間違いが続くときは計算量を増やさず、問題を図や物で表します。

次の練習

  • 残った部分と引いた部分を合わせるともとの数になるか確かめたあと、同じ条件の別の数でもう一度説明させます。
  • 一人で説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
