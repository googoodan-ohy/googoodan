指導ガイド

短い場面を式に表す

取り除く場面とひき算の式を結びつける

全体から取り除いた部分をひいて、残った部分を求めます。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたのたし算・ひき算

指導の進め方

  1. まず1問を言葉で説明しながら解きます。その後は、お子さんが自分で計算し、答えが表す数や個数を読むようにします。
  2. 場面の中で、はじめにあった量、取り除いた量、残った量を区別します。
  3. 絵やものを使って場面を表し、どの計算が合うか話します。
  4. 式を書き、答えが何の個数なのか言葉で答えます。

例題と解き方

箱にチョコレートが8個あり、3個取り出しました。何個残っていますか。式と答えを書きましょう。

  1. 箱にあったチョコレート8個から、取り出した3個をひくと8−3=5です。
  2. チョコレートは5個残っています。5+3=8で確かめます。
例題の答えを見る（式）8−3=5、（答え）5個

よくある間違いと教え方

問題に出てくる全体の数と取り除いた数を入れ替えて書きます。

問題から、はじめにあった数と取り除いた数を見つけて式に入れさせましょう。

計算結果だけを書き、考えた理由を説明しません。

初めの2問は、計算した理由を短く言わせましょう。

理解度を確かめる質問

  • 式の2つの数は、問題の中のそれぞれ何を表しているのかな？
  • 箱にチョコレートが8個。3個取り出したら、あと何個？
  • この数をものや位ごとのまとまりで表すと、どうなるかな？

プリントの活用と丸つけ後の指導

まず、例題の式8−3=5と答えの5個をお子さんが説明できるか見ます。残った部分とひいた部分を合わせるとはじめの数になるかに注目します。初めの2問は考え方を言わせ、その後の3問は1人で解かせます。同じまちがいが続く場合は問題数を増やさず、問題の表し方を絵やものに変えます。

次の練習

  • 残った部分とひいた部分を合わせるとはじめの数になることを確かめてから、同じ条件の別の数でもう一度説明させます。
  • 箱のチョコレート8個から3個を取り出す場面を図にし、残りが5個になることを一緒に見ます。
