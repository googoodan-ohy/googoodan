指導ガイド

絵の並びをかけ算の式に表す

同じ数のたし算をかけ算で表す

同じ数を繰り返したす式を、1つのまとまりの数×まとまりの数に置きかえます。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. 絵の全体、まとまり、1つずつのものを指で示します。実際に印をつけた結果を数や式に表し、絵と答えを照らし合わせます。
  2. 並びの1列の数と列の数を数え、かけ算の式に対応させます。
  3. 1列の数を列の数だけ繰り返したす式とかけ算の式を結びつけます。
  4. 1列の数×列の数=全体の数になるように、かけ算の式の空らんをうめます。

例題と解き方

1列に点が3こずつ、4列ある並びを見て、かけ算の式の空らんをうめましょう：□×□=□。

  1. 1列の点3こを1つのまとまりと考え、4列を4つのまとまりとして表します。
  2. 3が4回繰り返したされます。
  3. 同じ数3が4回あるので、かけ算の式は3×4=12です。
  4. 3×4=12です。繰り返される数とたした回数が合っているか確かめます。
例題の答えを見る3×4=12

よくある間違いと教え方

1列の数や列の数をまちがえて数え、かけ算の式に書きます。

並びの1列の数と列の数をそれぞれ数え、式の2つの数に対応させるよう促します。

絵を数えず、数字だけを見て答えます。

数字が絵のどの部分から出てきた数か、指してもらいます。

理解度を確かめる質問

  • 式の2つの数は、それぞれ絵の何を表しているのかな？
  • 例の3×4が12になる理由を、ものや計算を使って見せてくれる？
  • この並びを、同じ数を繰り返したす式で表すとどうなるかな？

プリントの活用と丸つけ後の指導

代表例のかけ算の式3×4=12を説明できるか、まず確かめます。まとまりの大きさとまとまりの数を、実際の絵から見分けられるかに注目します。最初の2問は解き方を話してもらい、そのあとの3問は1人で解いてもらいます。同じ間違いが続く場合は、計算量を増やさず、問題の表し方を絵やものに変えます。

次の練習

  • まとまりの大きさとまとまりの数を実際の絵から見分けられるか確かめたあと、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 横に3個ずつ、4段に点を並べて、式の3と4が図のどこを表すか確かめます。
