指導ガイド

お話をたし算の式に表そう

合わせる場面とたし算の式を結びつける

合わせる場面では、2つの部分を足して全体を求めます。

まず確認すること

  • 文章に出てくる物の数を捉える
  • 2つの部分の数を合わせて数える

指導の進め方

  1. まず1問を言葉で説明しながら解きます。その後は、子ども自身でたし算の式を書き、それぞれの数が何個を表すか読んでもらいます。
  2. 場面に出てくる2つの部分の数、または初めの数と増えた数を区別します。
  3. 絵や物で2つの量を合わせる場面を表し、たし算をする理由を話します。
  4. たし算の式を書き、和が何の数かを言葉で答えます。

例題と解き方

りんごが3個あります。りんごを2個持ってきました。場面をたし算の式に表しましょう。

  1. 初めにあったりんご3個と、持ってきたりんご2個を合わせるので、3+2と表します。
  2. りんごは全部で5個なので、3+2=5と書きます。
例題の答えを見る3+2=5

よくある間違いと教え方

場面に出てくる2つの数のうち、1つを式に書き忘れます。

場面に出てくる2つの量をどちらも式に書き、2つの数を足して全体を表しているか確かめてもらいましょう。

計算結果だけを書き、考えた理由を説明しません。

最初の2問は、計算した理由を短く話してもらいましょう。

理解度を確かめる質問

  • 式の2つの数は、場面の中の何をそれぞれ表しているかな？
  • もとからあったりんごは3個。2個増えたら、全部で何個かな？
  • この場面をたし算の式に表すのは、どうしてかな？

プリントの活用と丸つけ後の指導

まず、代表例の式3+2=5を子どもが説明できるか見ます。場面に出てくる2つの量と全体の数が、式に正しく表されているか観察します。最初の2問は考え方を話してもらい、その後の3問は一人で解いてもらいます。同じ間違いが続く場合は、計算量を増やさず、問題の表し方を図や物に変えます。

次の練習

  • 2つの部分を合わせた数と全体の数が同じか確認し、同じ条件の別の数でもう一度説明してもらいます。
  • 色紙を2枚ずつつなげた場面を、2+2=4で表してみます。
