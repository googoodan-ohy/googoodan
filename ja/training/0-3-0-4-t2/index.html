指導ガイド

何倍を表す絵とかけ算の式を結びつける

何倍の意味

何倍とは、基準の量をその回数分集めた大きさです。

まず確認すること

  • ものの数を数え、同じ数ずつにまとめる
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. まず左の問題を解き、右の選択肢から同じ答えや関係を見つけます。線を引く前に、残りの選択肢も確かめ、同じ選択肢を重ねて使わないようにします。
  2. 絵で、基準の量がいくつで、同じ量が何回繰り返されているかを見分けます。
  3. 絵やものを使って場面を表し、どの計算が合うか話します。
  4. 絵の基準の量と繰り返す回数に合うかけ算の式を見つけ、線で結びます。

例題と解き方

左の絵：基準の量3こが4回集まっています。右の選択肢：① 3×3 ② 3×4。合う選択肢と線で結びましょう。

  1. 絵では、基準の量が3こで、同じ量が4回あることを確かめます。
  2. 基準の量3こが4回あるので、かけ算の式は3×4です。
  3. 3×4は、絵の基準の量3こを4回表します。
  4. 右の② 3×4が絵を表しているので、結びつけます。
例題の答えを見る② 3×4

よくある間違いと教え方

絵の基準の量と繰り返す回数を、かけ算の式の2つの数に逆に対応させます。

絵の基準の量がいくつで、何回繰り返されているか確かめてから、かけ算の式の2つの数に対応させます。

絵の形が似ているという理由だけで結びつけます。

両方が同じ数や同じ計算を表しているか説明してもらいます。

理解度を確かめる質問

  • 式の2つの数は、それぞれ絵の何を表しているのかな？
  • 例の3×4が12になる理由を、ものや計算を使って見せてくれる？
  • 結びつけた両方が同じ答えだと、どうしてわかるのかな？

プリントの活用と丸つけ後の指導

代表例で、絵の基準の量と繰り返す回数を見つけ、合うかけ算の式と結びつけた理由を説明できるか見ます。結びつける前に、絵と式が同じ量を表しているか確かめます。

次の練習

  • まとまりの大きさとまとまりの数を実際の絵から見分けられるか確かめたあと、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 左の絵では3個ずつのまとまりが4つあります。3×4の式にある3と4が図のどこにあたるか見つけます。
