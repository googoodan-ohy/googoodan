余りのあるわり算

わる数が何回入るかを求め、残った数がわる数より小さいかを確かめます。

まず確認すること

  • かけ算九九
  • ひき算と位の値

指導の進め方

  1. 間違った解き方を上から順に、一段階ずつ確かめさせます。最初に間違ったところを見つけたら、その段階から計算し直し、右の欄に正しい解き方を書きます。
  2. わる数のかけ算九九から、わられる数をこえないいちばん大きな積を見つけ、商が合っているか確かめます。
  3. わられる数から、商とわる数をかけた数をひいて、余りが合っているか確かめます。
  4. わる数×商+余りが最初の数と同じか、余りがわる数より小さいかを確かめます。

例題と解き方

23÷4で、ある子が4×5=20、23−20=4と計算し、商は5、余りは4と書きました。間違いを見つけて、正しく直して書きましょう。

  1. まず、4×5=20と23−20=4を、それぞれ計算し直します。
  2. 4×5=20は正しいです。
  3. 23−20=4が間違いです。23−20=3なので、商は5、余りは3です。
  4. 4×5+3=23です。3<4なので、余りの条件にも合っています。
  5. したがって、23−20=4を23−20=3に直し、余りも4から3に直します。
例題の答えを見る商 5、余り 3

よくある間違いと教え方

残った数がわる数以上なのに、計算をやめます。

もう1つ分のまとまりを作れるか確かめて、商と余りを求め直してください。

答えだけを直し、間違った途中の計算を残します。

最初に間違った段階と、直した理由を一緒に話させてください。

理解度を確かめる質問

  • この余りで、もう1つ分のまとまりを作れるかな？
  • 4×5に3をたすと、23になるかな？
  • 23−20=4は合っているかな？

プリントの活用と丸つけ後の指導

例題の23÷4で、どこから計算が違っているか一緒に見つけます。商5とあまり3が合うこと、あまりが4より小さいことも確認しましょう。間違いをすぐ直すのではなく、最初に違った計算を指して、どう直せばよいか話してもらいます。

次の練習

  • 商とあまりを逆に書いていないか、あまりがわる数より小さいか確かめてから、別の数でも最初に違った計算を探してもらいます。
  • 23から20を引くと3です。商5・あまり3に直せるか、計算を一緒に見直してみましょう。
