指導ガイド

絵を見て式を完成させる

合わせる場面とたし算の式を結びつける

合わせる場面では、2つの部分を足して全体を求めます。

まず確認すること

  • 絵にある物の数を数える
  • 2つの部分と全体を区別する

指導の進め方

  1. 絵の2つの部分と全体を指で示します。それぞれの部分の数を数え、式の数と照らし合わせます。
  2. 式にすでに書かれている数が、絵のどの部分を表すか確認します。
  3. 残りの部分の数と全体の数を数え、それぞれ合う空らんに書きます。
  4. 完成したたし算の式を読み、2つの部分を合わせた数が全体の数と同じか確認します。

例題と解き方

りんごの絵（●●● / ●●）を見て、3+□=□の空らんをうめましょう。

  1. 絵の2つの部分を数えると、それぞれ3個と2個です。
  2. 2つの部分を合わせると、全部で5個です。
  3. 1つ目の空らんに2、2つ目の空らんに5を書いて、3+2=5を完成させます。
例題の答えを見る3+2=5

よくある間違いと教え方

絵の2つの部分のうち、片方だけを数えて式を完成させます。

絵の2つの部分をそれぞれ数え、2つの数を足した数が全体の数と同じか確かめてもらいましょう。

絵を数えず、数字だけを見て答えます。

その数字が絵のどの部分から出てきたのか、指してもらいましょう。

理解度を確かめる質問

  • 式の2つの数は、絵の中の何をそれぞれ表しているかな？
  • 例の3+2が5になる理由を、絵で見せてくれるかな？
  • 最初の空らんには、どっちのりんごの数が入る？ 次の空らんは、全部の数かな？

プリントの活用と丸つけ後の指導

まず、代表例の式3+2=5を子どもが説明できるか見ます。2つの部分の数と全体の数が、それぞれ合う場所に書かれているか確認します。プリントでも、絵を数えて空らんを埋めたあと、完成した式をもう一度読んでもらいます。

次の練習

  • 2つの部分を合わせた数と全体の数が同じか確認し、同じ条件の別の数でもう一度説明してもらいます。
  • 1問目の絵を数えて、2+□=□の二つの空らんを埋めます。
