指導ガイド

2つの数の間に不等号を入れる

小数の大きさを比べる

この活動の学習内容は「小数の大きさを比べる」です。「2つの数の間に不等号を入れる」方法で練習します。小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知っていること
  • 同じ位の数字を区別し、整数の基本的な計算ができること

指導の進め方

  1. 小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。
  2. 4.9と5の大きさは、一の位から比べます。
  3. 一の位では4は5より小さいので、4.9 < 5です。二つの数の大きさが等しいときは=を書きます。
  4. まず1問を言葉で説明し、同じ方法で次の問題を解きます。

例題と解き方

4.9と5の間にあてはまる不等号を書きましょう：4.9 [ ] 5

  1. 4.9と5の一の位を比べます。4は5より小さいです。
  2. したがって、4.9は5より小さいです。
  3. 二つの数の間に<を入れます。
  4. 4.9 < 5です。
  5. 入れた不等号が二つの数の大小関係に合っているか確かめます。
例題の答えを見る4.9 < 5

よくある間違いと教え方

小数部分を一つの整数のように読んだり比べたりする

小数点の後の数字は順に読みます。大きさを比べるときは、一の位から同じ位を順に見ます。

答えだけを見て、解き方の理由を省いてしまう

まず1問を言葉で説明し、同じ方法で次の問題を解きます。

理解度を確かめる質問

  • この問題の4.9と5を比べるとき、一の位からどのように見ればいいかな？
  • 4.9は5より小さいね。5を5.0と考えて比べるとどうかな？
  • 6.6と6.60は同じ大きさかな？末尾の0を取って比べてみよう。

プリントの活用と丸つけ後の指導

最初は3～5問を一緒に読み、残りはお子さんが解きます。二つの数の間に記号を間違えて入れた問題は、同じ位の数字を大きい位から比べる方法をもう一度説明してから、数字を変えた問題を1問だけ確認します。速さよりも、同じ間違いが繰り返されているかを見てください。

次の練習

  • 代表例の4.9 < 5を答えを隠してもう一度解き、同じ条件の新しい問題2問に取り組みます。
  • 「2つの数の間に不等号を入れる」で説明に困った段階だけ、もう一度練習します。数字を読むのが難しければ位取り表、大きさを比べるのが難しければ同じ位の数字を比べる方法を確認し、つまずきの原因を見分けます。
