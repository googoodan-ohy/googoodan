指導ガイド

数直線の空らんの数を書く

0の意味と0〜9の数の順序

数直線上で数の並びを見て、空らんに入る数を見つける方法を学びます。

まず確認すること

  • 物を一つずつ指でさす

指導の進め方

  1. 数直線に書かれた数を見て、目盛りの間の一つ分ごとに数が1ずつ大きくなるか確かめます。空らんの前後の目盛りを見て、ぬけている数を見つけます。
  2. 数直線の目盛りを左から見て、数の順序を確かめます。
  3. すでに確かめた目盛りと空らんに印をつけ、見落とした場所がないようにします。
  4. 空らんに合う数を書き、数直線の数を順に読みます。

例題と解き方

目盛りの間隔が等しい数直線に、左から0, 1, 2, 空らん, 4と順に書かれています。空らんに合う数を書きましょう。

  1. 0から、一つ進むごとに1ずつ大きくなります。
  2. 2の次の数は2+1=3です。
例題の答えを見る3

よくある間違いと教え方

目盛りの間の一つ分を飛ばしたり、二つ分として数えたりして、数を間違えます。

数直線上を目盛り一つ分ずつ進み、数がどう変わるか言わせます。

目盛りの線の本数と、線と線の間の区間の数を混同します。

始めの目盛りから一つ分進むたびに、数がいくつ変わるか言わせます。

理解度を確かめる質問

  • 数直線で、空らんの前と後の数は何かな？
  • 0、1、2と進んだら、次は何かな？
  • 3を入れて、0から4まで順に読んでみよう。1ずつ増えているかな？

プリントの活用と丸つけ後の指導

まず、例の答え3を子どもが説明できるか見ます。目盛りの間の一つ分を正しく確かめたかを観察します。空らんを一つうめたら、数直線の前後の目盛りと数をもう一度確かめさせます。答えだけ合っていた場合も、どの数がぬけていたのか理由を確かめます。

次の練習

  • 数直線の目盛りの間の一つ分を正しく確かめたか見てから、同じ条件の別の数直線で説明させます。
  • 自分だけで説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
