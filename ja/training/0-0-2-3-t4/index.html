指導ガイド

数を位ごとに分けよう

4けたの数の位の値

数字は置かれた位によって表す値が変わります。0は、その位にまとまりがないことを表します。

まず確認すること

  • 10個ずつまとめる
  • 1けたの数を読む

指導の進め方

  1. 空らんが何の位の数かを考えます。数を入れたら、右側の数を全部足して、左側の数になるか確かめましょう。
  2. 右から一の位・十の位・百の位・千の位を確認します。
  3. それぞれの数字に位の大きさをかけて、表す値を見つけます。
  4. 位ごとの値を足して、もとの数を作り直します。

例題と解き方

3047を位の値に分けて表しましょう。

  1. 3047の0でない位の値を見つけます。
  2. 3000 + 40 + 7 = 3047です。
  3. 百の位の数字が0でも、位取り表には0を書きます。
例題の答えを見る3000 + 40 + 7

よくある間違いと教え方

真ん中の0を消して、別の数として読んでしまいます。

空いている位にまとまりがないことと、位がないことは違います。位取り表には0を残しましょう。

空らんの前後の数字を、いつも足してしまいます。

まず空らんが何を表すのか話してもらい、計算方法を選びましょう。

理解度を確かめる質問

  • この数字は、この位でいくつを表しているかな？
  • 3000と40と7を合わせると、いくつになる？
  • 空らんをうめると、＝の左と右は同じ数になるかな？

プリントの活用と丸つけ後の指導

まず、代表例の答えである3000 + 40 + 7を子どもが説明できるか確認します。見るポイントは、数字そのものではなく、その位のまとまりの大きさを読めているかどうかです。空らんを1つ埋めたあと、その前後の式や並びをもう一度読んでもらいます。答えが合っていても、どの数が抜けていたのか理由を確かめます。

次の練習

  • 数字そのものではなく、その位のまとまりの大きさを読めているか確認したうえで、同じ条件の別の数でもう一度説明してもらいます。
  • 3,047を位取り表に書き、百の位に0を残す意味を確かめます。
