指導ガイド

まとまりの数と全体の数を書く

同じ数ずつまとめる

絵からまとまりの数を数え、各まとまりの数をたして全体の数を求めます。

まず確認すること

  • ものの数を1つずつ数える
  • 簡単なたし算をする

指導の進め方

  1. まず1問、解き方を言葉で説明しながら解きます。そのあとは子ども自身に計算させ、答えが表す数や個数を読ませます。
  2. 絵からまとまりの数と1つのまとまりの大きさを確かめてから、全体の数を数えます。
  3. 各まとまりに入っている数をたすか、1つずつ数えて全体の数を確かめます。
  4. まとまりの数と全体の数をそれぞれ書き、何を数えた数か説明します。

例題と解き方

次の絵を見て、まとまりの数と全体の数を書きましょう：(●●●) (●●●) (●●●) (●●●)。

  1. 絵の中で、1つのまとまりに入っている数とまとまりの数を区別して印をつけます。
  2. 1つのまとまりに3個ずつ入っています。
  3. 3個ずつのまとまりが4つなので、全体の数は3+3+3+3=12個です。
  4. まとまりの数は4まとまりで、全体の数は12個です。
例題の答えを見るまとまりの数4まとまり、全体の数12個

よくある間違いと教え方

まとまりの数と全体の数を取り違えて書きます。

絵の中のまとまりの数と、ものの総数をそれぞれもう一度数えさせましょう。

答えだけを書き、解き方の理由を説明しません。

最初の2問は、計算した理由を短く説明させましょう。

理解度を確かめる質問

  • 絵では、1つのまとまりに何個ずつ入っていて、まとまりはいくつあるかな？
  • 例の3+3+3+3が12になる理由を、絵で見せてくれる？
  • まとまりの数と全体の数は、絵のどの部分を数えた数かな？

プリントの活用と丸つけ後の指導

まず、例の答えであるまとまりの数4まとまりと全体の数12個を子どもが説明できるか確かめます。まとまりの数と全体の数を、実際の絵で区別できているかに注目します。最初の2問は解き方を説明させ、そのあとの3問は一人で解かせます。同じ間違いが続くときは計算量を増やさず、物を使ってまとまりの数と全体の数をそれぞれ数えさせます。

次の練習

  • まとまりの数と全体の数を絵から区別できるか確かめたあと、同じ条件の別の絵でもう一度説明させます。
  • 点を囲み、囲みの数と点の総数を別々に数えて書きます。
