指導ガイド

計算のまちがいを見つけて直す

分数のたし算・ひき算を組み合わせて練習する

分数のたし算・ひき算を組み合わせて練習するための指導資料です。複数の計算が混在していても、分数の単位と計算の意味をまず確認します。たし算かひき算かを確認することが出発点です。答えがまちがっている式を見つけ、どこでまちがえたのか子どもに説明してもらいます。正しい部分はそのままにして、その箇所から計算し直させます。

まず確認すること

  • 1つの全体と、同じ大きさに分けた部分を区別する
  • 分母と分子が表す数を説明する
  • 約数・倍数と約分、仮分数・帯分数の変換

指導の進め方

  1. 演算記号を説明させ、計算のまちがいを見つけて正しく直します。
  2. まず、もとの計算を別に解いて、答えの大きさを予想します。
  3. まちがった行を見つけ、なぜ値が変わったのかを言葉で説明させます。
  4. 代表例題のまちがいの原因と直した結果を、子どもにもう一度説明させます。

例題と解き方

まちがった計算3/4 − 1/3 = 1を直しましょう。

  1. 3/4から正の数1/3を引くと3/4より小さくなるので、1はまちがった答えです。
  2. 分母が異なるので、通分してから分子どうしを引きます。
  3. 9/12 − 4/12に通分します。
  4. 3/4 − 1/3 = 5/12
例題の答えを見る5/12

よくある間違いと教え方

たし算とひき算に同じ計算手順を当てはめる

たし算とひき算の計算のきまりをそれぞれ確認し、初めて値が変わった段階を見つけて直してから、もう一度計算して確かめます。

まちがった答えだけ消して、理由を確かめない

計算のきまりをまちがえて使った最初の段階と、単純な計算まちがいを区別して示します。

理解度を確かめる質問

  • 計算で最初にまちがえたところはどこかな？
  • 求めた数をもとの式に入れると、等号の両側は同じ値になるかな？
  • 3/4−1/3=1は、どこがまちがっているかな？

プリントの活用と丸つけ後の指導

最初は3~5問を一緒に見て、同じまちがいが繰り返されるかを確認します。答えがまちがっている式を見つけ、どこでまちがえたのか子どもに説明してもらいます。正しい部分はそのままにして、その箇所から計算し直させます。単位の説明があいまいなときは、計算量を増やさず、その概念の図や変換の練習に戻ります。

次の練習

  • 同じ数を使って、たし算の式とひき算の式を1組作る
  • 分母が同じ場合と異なる場合の計算方法を比べ、通分が必要か判断する
