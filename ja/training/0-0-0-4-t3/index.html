指導ガイド

数直線の空らんに数を書く

数直線上で数の位置を見つける

等間隔の目盛りは同じ数の差を表します。始めの数と一目盛りの大きさを確かめて、位置を見つけます。

まず確認すること

  • 数の順序
  • 一つずつ数える

指導の進め方

  1. 始めの目盛りと目盛りの間の数の差を読み、空らんに入る数を見つけます。
  2. 数直線の始めの数を読みます。
  3. 隣り合う目盛りの数から、一目盛りの大きさを確かめます。
  4. 空らんに数を書き、前後の目盛りの数が同じ差で大きくなっているか確かめます。

例題と解き方

目盛りの間隔が等しい数直線に、0, 2, 4, □と順に書かれています。□に合う数を書きましょう。

  1. 数直線で0から2ずつ大きくなる目盛りの数を読みます。
  2. 0, 2, 4の次の数は4+2=6です。
  3. 空らんに6を書き、並びが0, 2, 4, 6になるか確かめます。
例題の答えを見る6

よくある間違いと教え方

始めの目盛りを最初の一目盛りとして数えます。

出発点の目盛りは数えず、目盛りの線と線の間を一つずつたどって区間を数えます。

目盛りの線の本数と、線と線の間の区間の数を混同します。

始めの目盛りから一つ分進むたびに、数がいくつ変わるか言わせます。

理解度を確かめる質問

  • 目盛りの間の一つ分は、いくつを表しているかな？
  • 例で4の次の目盛りの数が6になるわけを説明してくれる？
  • 6を入れて、0、2、4、6と読んでみよう。いくつずつ増えているかな？

プリントの活用と丸つけ後の指導

まず、例の答え6を子どもが説明できるか見ます。目盛りの間隔をとらえたかを観察します。空らんを一つうめたら、その前後の数と並びをもう一度読ませます。答えだけ合っていた場合も、どの数がぬけていたのか理由を確かめます。

次の練習

  • 目盛りの間隔をとらえたか確かめてから、同じ条件の別の数でもう一度説明させます。
  • 自分だけで説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
