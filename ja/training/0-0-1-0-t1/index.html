指導ガイド

2つのまとまりの絵を合わせて数を書く

5までの数を合わせる

二つのまとまりを合わせて、全体の個数を求める関係を学びます。

まず確認すること

  • 全体の個数を数える

指導の進め方

  1. 左のまとまりと右のまとまりをそれぞれ指さして数えます。それぞれの個数と、合わせた個数を式の欄に書き、絵と見比べます。
  2. 絵の一つ目のまとまりと二つ目のまとまりの数をそれぞれ数えます。
  3. 二つのまとまりを合わせて、全体の個数を数えます。
  4. 二つのまとまりの数を足した値が、絵全体の個数と同じか確かめます。

例題と解き方

2個と3個を合わせると、全部で何個ですか。まず、物やまとまりを描いて、数字が表す部分を示しましょう。

  1. 2個のまとまりと3個のまとまりを描き、それぞれの個数を確かめます。
  2. 一つ目のまとまりは2個、二つ目のまとまりは3個です。
  3. 2+3=5なので、全部で5個です。
例題の答えを見る5

よくある間違いと教え方

部分の数を全体の数だと思い込みます。

絵の二つのまとまりを実際の物で合わせ、全体の数と対応させます。

絵を数えず、数字だけを見て答えます。

数字が絵のどの部分から出てきた数か指でささせます。

理解度を確かめる質問

  • 二つのまとまりを合わせると、全部で何個になるかな？
  • ブロック2個と3個を一緒にすると、何個になるかな？
  • 5個のブロックを、2個と3個に分けてみよう。

プリントの活用と丸つけ後の指導

まず、例の答え5を子どもが説明できるか見ます。二つのまとまりを数えもらしたり重ねて数えたりせず、合わせて数えたかを観察します。初めの二問は考え方を言わせ、その後の三問は一人で解かせます。同じ間違いが続くときは計算量を増やさず、問題を絵や物で表します。

次の練習

  • 二つのまとまりを数えもらしたり重ねて数えたりせず、合わせて数えたか確かめてから、同じ条件の別の数でもう一度説明させます。
  • 自分だけで説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
