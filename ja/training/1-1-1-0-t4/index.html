指導ガイド

まちがった計算の手順を直す

真分数＋真分数・和が1未満

分母が同じ真分数のたし算では、分母はそのままにして分子を足します。このプリントでは、分母まで足したまちがいを見つけて直します。

まず確認すること

  • 全体の1と、同じ大きさに分けた部分を区別する
  • 分母と分子が表す数を説明する
  • 約数・倍数、約分、仮分数・帯分数の変換

指導の進め方

  1. 2つの分数の分母が同じことを見て、分母はそのまま、分子どうしを足します。
  2. まず元の計算を別に行い、答えのおよその大きさを予想します。
  3. まちがった行を見つけ、なぜ値が変わったのか言葉で説明させます。
  4. 代表例のまちがいの原因と直した結果を、子どもにもう一度説明させます。

例題と解き方

まちがった解き方：2/4 + 1/4 = 3/8。まちがいを直しましょう。

  1. まちがいの理由：分母まで足して単位が変わっています。分母が同じなら、そのままにします。
  2. 分母はそのままにして、分子どうしを足します。
  3. 2/4 + 1/4 = 3/4です。3/4はこれ以上約分できず、1より小さい分数です。
  4. 分母は4のまま、分子だけを足します。
  5. 3/4から1/4を引くと、もとの2/4に戻ります。
例題の答えを見る3/4

よくある間違いと教え方

分母まで足す

分母は単位分数の大きさを表します。分子を計算する前に、2つの単位分数の大きさが同じか説明させます。

まちがった答えだけを消して、理由を確かめない

計算のきまりをまちがえて使った最初の段階と、単純な計算ミスを区別して示します。

理解度を確かめる質問

  • 分母は足さず、分子だけを足すのはどうしてかな？
  • 求めた和が1より大きいか小さいか、分子と分母から確かめてくれる？
  • 2/4 + 1/4の分母が4のままなのは、どうしてかな？

プリントの活用と丸つけ後の指導

分母まで足したまちがいと、計算は合っているけれど答えを約分していない場合を分けて見ます。

次の練習

  • 和が1未満の場合と1以上の場合を並べて解く
  • 求めた和から一方の項を引き、もう一方の項に戻るか確かめる
