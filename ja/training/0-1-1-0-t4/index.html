指導ガイド

たし算のまちがいを直そう

和が9以下のたし算

2つの数を合わせて、全部でいくつになるかを求めます。答えはどれも9以下です。数えにくいときは、ブロックを使って確かめましょう。

まず確認すること

  • 10までの数を数える
  • 2つの部分と全体の関係

指導の進め方

  1. 与えられた2つの数と、子どもが書いた和を確認します。2つの数をもう一度足して間違いを見つけ、右側に正しい式を書きます。
  2. それぞれの数の分だけブロックを用意し、合わせる2つのまとまりを確かめます。
  3. 2つの数を足して和を書きます。
  4. 和から一方の数を引くと、もう一方の数になるか確かめます。

例題と解き方

2+2=3と書いた計算の間違いを見つけて、正しく直しましょう。

  1. 子どもが書いた2つの数2と2、和の3を確認します。
  2. 2+2=4なので、和は4です。
  3. 4−2=2なので、和が4で正しいか確かめられます。
  4. 間違って書かれた和3を4に直し、右側に正しい式2+2=4を書きます。
例題の答えを見る2+2=4

よくある間違いと教え方

2つのまとまりの物を一緒に数えるとき、1つ数え忘れたり、同じ物を2回数えたりします。

2つの数をそれぞれ確かめてから、一緒に数えてみましょう。

答えだけを直し、どの計算が間違っていたか確かめません。

どのたし算が間違っていたのか、直した理由と一緒に話してもらいましょう。

理解度を確かめる質問

  • 和から1つ目の数を引くと、どんな数が残るかな？
  • 2個と2個を合わせると何個？ 書いてある3で合っているかな？
  • この式は、どこを直せばいいかな？

プリントの活用と丸つけ後の指導

まず、代表例の正しい式2+2=4を子どもが説明できるか見ます。2つの部分を合わせた数と全体の数が同じか観察します。間違いを見つけたらすぐに直させるのではなく、例のように間違った計算を指摘したあと、その理由を説明してもらいます。

次の練習

  • 2つの部分を合わせた数と全体の数が同じか確認し、同じ条件の別の数でもう一度説明してもらいます。
  • 1問目の2+2=3を2+2=4に直し、答えと式が合うことを確かめます。
