指導ガイド

同じ大きさの分数と小数を結びつける

分母が10の分数を小数で表す

分母が10の分数を小数に直し、同じ大きさのものを線で結ぶプリントです。7/10は0.1が7つ分なので0.7。分数と小数のどちらで表しても、大きさは同じです。

まず確認すること

  • 分母が10の分数を読む
  • 小数第1位が0.1を表すと分かる

指導の進め方

  1. 7/10は0.1が7つ分なので、0.7と表せます。
  2. 分母が10なら、分子の数を小数第1位に書きます。
  3. 0.7×10=7となることでも、7/10と0.7の大きさが同じだと確かめられます。
  4. 左の分数を小数に直し、右から同じ大きさの数を探して線で結びます。

例題と解き方

7/10と同じ値の小数を結びつけましょう。右：① 0.7 ② 1.7

  1. 7/10は0.1が7つ分なので0.7です。
  2. 0.7×10=7でも確かめられます。
  3. 右の0.7と線で結びましょう。
例題の答えを見る① 0.7

よくある間違いと教え方

分母が10の分数を小数第2位に書く

7/10は0.1が7つ分です。小数第1位に7を書いて0.7になることを、位取り表で見ます。

数字だけを見て、同じ大きさか確かめずに結ぶ

分数を小数に直してから、右の数と同じ大きさか確かめます。

理解度を確かめる質問

  • 7/10は0.1がいくつ分かな？
  • 0.7を10倍すると7になるね。7/10と同じ大きさかな？
  • 7/10は0.1が7こ分だね。同じ大きさの小数を探してみよう。

プリントの活用と丸つけ後の指導

7/10を0.7と表すところを、0.1のまとまりを7つ描いて確かめます。次の問題では、まず分母を見て小数の位を決め、最後に同じ大きさの数と結びましょう。

次の練習

  • 7/10が0.7になるわけを図で説明する。
  • 分母が100の分数でも、同じように小数で表せるか試す。
