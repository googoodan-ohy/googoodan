指導ガイド

同じ大きさを表す数を結びつける

末尾の0を除いても大きさが同じ小数

この活動の学習内容は「末尾の0を除いても大きさが同じ小数」です。「同じ大きさを表す数を結びつける」方法で練習します。小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知っていること
  • 同じ位の数字を区別し、整数の基本的な計算ができること

指導の進め方

  1. 小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。
  2. 5.40は5と40/100、5.4は5と4/10なので、同じ数です。
  3. 小数部分の末尾の0は消してもかまいませんが、5.04の真ん中の0を消すと値が変わります。
  4. 左側から一つ選んで値を求め、右側から同じ値を探します。線を引く前に、二つの表し方が同じ量である理由を説明してもらいます。

例題と解き方

左側の5.40と同じ値を表す右側の表現を結びましょう。右側：① 5.4 ② 6.4

  1. 小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。
  2. 5.40は5と40/100、5.4は5と4/10なので、同じ数です。
  3. 小数部分の末尾の0は消してもかまいませんが、5.04の真ん中の0を消すと値が変わります。
  4. 5.40と5.4は同じ大きさを表します。
  5. 左側の数と同じ大きさの表現を右側から探して結びます。
  6. 左側の値は5.4なので、右側の①と結びます。②はそれより1大きい数です。
例題の答えを見る① 5.4

よくある間違いと教え方

小数部分を一つの整数のように読んだり比べたりする

小数点の後の数字は順に読みます。大きさを比べるときは、一の位から同じ位を順に見ます。

答えだけを見て、解き方の理由を省いてしまう

左側から一つ選んで値を求め、右側から同じ値を探します。線を引く前に、二つの表し方が同じ量である理由を説明してもらいます。

理解度を確かめる質問

  • この問題の5.40では、それぞれの数字がどの単位を表しているか話してみよう。
  • 5.40の最後の0を取ると5.4になるね。同じ大きさかな？
  • 6.6と6.60は、末尾の0を取っても同じ大きさかな？

プリントの活用と丸つけ後の指導

最初は3～5問を一緒に読み、残りはお子さんが解きます。「同じ大きさを表す数を結びつける」で間違えた問題は、小数部分の末尾に0をつけたり消したりしても大きさが変わらないことをもう一度説明してから、数字を変えた問題を1問だけ確認します。速さよりも、同じ間違いが繰り返されているかを見てください。

次の練習

  • 代表例の5.40を答えを隠してもう一度解き、同じ条件の新しい問題2問に取り組みます。
  • 「同じ大きさを表す数を結びつける」で説明に困った段階だけ、もう一度練習します。数字を読むのが難しければ位取り表、計算が難しければ整数の計算を確認し、つまずきの原因を見分けます。
