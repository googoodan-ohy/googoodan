指導ガイド

絵の中のものを同じ数ずつに分ける

同じ数ずつまとめる

絵の中のものを決まった数ずつまとめて、まとまりの数を数えます。

まず確認すること

  • ものの数を1つずつ数える
  • 同じと違うの意味を理解する

指導の進め方

  1. 絵の中のものを決まった数ずつまとめて印をつけます。1つのものが2つのまとまりに入ったり、抜けたりしていないか確かめます。
  2. 絵から、1つのまとまりに入っている数と、まとまりの数をそれぞれ見つけます。
  3. どのまとまりも同じ数ずつ入っているか確かめて、まとまりを1つずつ数えます。
  4. まとまりの数を書き、1つのまとまりに入っている数と区別して説明します。

例題と解き方

次の点12個を3個ずつまとめて、まとまりの数を書きましょう：● ● ● ● ● ● ● ● ● ● ● ●。

  1. 点12個を3個ずつまとめて印をつけます。
  2. 1つのまとまりに3個ずつ入っています。
  3. まとまりを1つずつ数えると、4つです。3個ずつのまとまりが4つなので、3+3+3+3=12です。
  4. 3×4=12です。まとまりの数と全体の数が絵と合っているか確かめます。
例題の答えを見る4まとまり

よくある間違いと教え方

まとまりの大きさとまとまりの数を取り違えて数えます。

1つのまとまりに入っている数と、まとまりの数を別々に数え、絵の中でそれぞれ確かめさせましょう。

絵を数えずに、数字だけを見て答えます。

その数字が絵のどの部分から出てきたのか、指し示させましょう。

理解度を確かめる質問

  • 1つのまとまりに入っている数と、まとまりの数はそれぞれいくつかな？
  • 例の点12個を3個ずつまとめると4つになる理由を、絵で見せてくれる？
  • すべての点を1回ずつだけまとめたことは、どうすれば確かめられるかな？

プリントの活用と丸つけ後の指導

まず、例の答えが4まとまりになる理由を子どもが説明できるか確かめます。まとまりの大きさとまとまりの数を、実際の絵で区別できているかに注目します。最初の2問は実際にまとめて印をつけながら解き方を説明させ、そのあとの3問は一人で解かせます。同じ間違いが続くときは計算量を増やさず、物を実際に同じ数ずつまとめさせます。

次の練習

  • まとまりの大きさとまとまりの数を実際の絵で区別できるか確かめたあと、同じ条件の別の数でもう一度説明させます。
  • 12個の点を3個ずつ囲み、4つのまとまりになるか確かめます。
