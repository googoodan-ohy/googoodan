まちがった計算の手順を直す

3けたのひき算（くり下がりなし）

同じ位どうしをひいて、残った数や2つの数の差を求めます。このタイプでは、どの位も上の数字が下の数字より小さくないので、まとまりを分けずに計算します。

まず確認すること

  • 各位の数字が表す数を理解していること
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. まちがった計算を上から一つずつ確かめてもらいます。最初にまちがえたところを見つけたら、その段階から計算し直し、右の欄に正しい計算を書きます。
  2. ひく数と最初の数の同じ位をそろえます。
  3. 一の位から、上の数字から下の数字をひきます。
  4. 求めた差にひく数をたすと、最初の数になるか確かめます。

例題と解き方

786 − 352を計算しましょう。ある子が答えを「435」と書きました。まちがいを直しましょう。

  1. 書かれた答えだけを見て判断せず、もとの式と計算を確かめましょう。
  2. 一の位：6−2=4。
  3. 十の位：8−5=3。
  4. 百の位：7−3=4。
  5. 差は434です。434+352=786となることを確かめます。
  6. 正しい答えは434です。一の位は6−2=4。ここをもう一度計算して、435になった理由を探しましょう。
例題の答えを見る434

よくある間違いと教え方

たし算のように計算したり、上下の数字を入れ替えたりします。

最初の数からひく数の分だけ実際に取り除き、残った数を数えてみましょう。各位でどちらの数からどちらの数をひくのか読みます。

答えだけ直して、まちがった途中の計算を残します。

最初にまちがえた段階と、直した理由をいっしょに話してもらいましょう。

理解度を確かめる質問

  • 差にひいた数をもう一度たすと、最初の数になるかな？
  • 786−352を一の位から計算すると、答えはいくつになった？
  • 435になったのは、どの位の計算かな？一の位の6−2を見直してみよう。

プリントの活用と丸つけ後の指導

まず、例の答え434になるわけを子どもが説明できるか見ます。残った部分とひいた部分を合わせると、最初の数になるかが確認するポイントです。まちがった答えを見てすぐ直させず、例のように最初にまちがえた計算を指し、その理由を説明してもらいます。

次の練習

  • 残った部分とひいた部分を合わせると最初の数になるか確かめてから、同じ条件の別の数でもう一度説明してもらいます。
  • 一人で説明するのが難しければ、例の数をもっと小さくして、ものを使って確かめます。
