指導ガイド

位ごとに分けた数を1つの数に表す

小数の位の値と数字が表す数

この活動の学習内容は「小数の位の値と数字が表す数」です。「位ごとに分けた数を1つの数に表す」方法で練習します。小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知っていること
  • 同じ位の数字を区別し、整数の基本的な計算ができること

指導の進め方

  1. 小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。
  2. まず1問を言葉で説明し、同じ方法で次の問題を解きます。

例題と解き方

2 + 0.4 + 0.09を小数で表しましょう。

  1. 小数第1位の単位は0.1、第2位の単位は0.01、第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が異なります。
  2. 2 + 0.4 + 0.09 = 2 + 0.49 = 2.49です。0.4を0.40と見て、小数の位をそろえます。
例題の答えを見る4.32

よくある間違いと教え方

0.4と0.09を足すとき、位をそろえずに0.13としてしまう

0.4は0.40と考えます。0.40 + 0.09 = 0.49なので、位をそろえて計算しましょう。

答えだけを見て、解き方の理由を省いてしまう

まず1問を言葉で説明し、同じ方法で次の問題を解きます。

理解度を確かめる質問

  • 2 + 0.4 + 0.09を小数で表すには、どの位から合わせればいいかな？
  • 2.49を2 + 0.4 + 0.09に戻して確かめられるかな？
  • 2 + 0.4 + 0.09では、0.4と0.09を合わせるといくつになるかな？

プリントの活用と丸つけ後の指導

最初は3～5問を一緒に読み、残りはお子さんが解きます。「位ごとに分けた数を1つの数に表す」で間違えた問題は、小数の位の値と数字が表す数の単位をもう一度説明してから、数字を変えた問題を1問だけ確認します。速さよりも、同じ間違いが繰り返されているかを見てください。

次の練習

  • 代表例の4+0.3+0.02を答えを隠してもう一度解き、同じ条件の新しい問題2問に取り組みます。
  • 「位ごとに分けた数を1つの数に表す」で説明に困った段階だけ、もう一度練習します。数字を読むのが難しければ位取り表、計算が難しければ整数の計算を確認し、つまずきの原因を見分けます。
