指導ガイド

絵を同じ数ずつのまとまりにする

10個ずつまとめて数える

ものを10個ずつまとめ、まとまりの数と残ったばらの数で表します。

まず確認すること

  • 10まで数える
  • 10のまとまりとばら

指導の進め方

  1. 絵にある全体、まとまり、ばらを指で示します。自分で印をつけた結果を数や式に表し、絵と答えを照らし合わせます。
  2. 絵のものを10個ずつ囲んでまとめます。
  3. まとまりの数を数え、1つのまとまりが10個という意味を言葉にします。
  4. まとまりの数と残ったばらの数を、それぞれ数えます。

例題と解き方

ものが12個あります。まず、ものを描いて10個ずつまとめましょう。まとまりはいくつ、ばらはいくつですか？

  1. 12個のうち10個を1つのまとまりにすると、まとまりは1つです。
  2. 残った2個は、ばら2個です。
  3. したがって、まとまり1つ、ばら2個です。
例題の答えを見るまとまり1つ、ばら2個

よくある間違いと教え方

まとまりの数と全体の個数を混同します。

まとまりの数は1、全体の個数は12と対応させて区別してください。

絵を数えず、数字だけを見て答えます。

その数字が絵のどの部分から出たのか、指で示させてください。

理解度を確かめる質問

  • まとまりはいくつで、ものは全部でいくつかな？
  • 10個を囲んだら、外に何個残ったかな？
  • 12個を10個ずつ囲んでみようか。

プリントの活用と丸つけ後の指導

12個の絵から10個を囲み、まとまりが1つ、ばらが2個になるところを指で示してもらいます。「まとまりは1つ」と「ものは10個」の数え方の違いは、実物でも確かめてみましょう。

次の練習

  • 12個を10個のまとまり1つとばら2個に分けられたら、13個でも試してみましょう。
  • 一人で説明するのが難しければ、例題の数をより小さな数に変え、ものを使って確かめます。
