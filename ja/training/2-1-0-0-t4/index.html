合わせる関係図を完成させる

0.1単位どうしを合わせる

この活動の学習内容は「0.1単位どうしを合わせる」です。「合わせる関係図を完成させる」方法で練習します。一の位どうし、小数第一位どうしをたします。小数点以下の桁数が異なるときは、空らんに0を書いて位をそろえます。

まず確認すること

  • 小数第一位・第二位・第三位の単位を知っている
  • 同じ位の数字を見分け、整数の基本的な計算ができる

指導の進め方

  1. 一の位どうし、小数第一位どうしをたします。小数点以下の桁数が異なるときは、空らんに0を書いて位をそろえます。
  2. 空らんの前後の式を一緒に読みます。示された計算の過程から必要な単位や数を求め、入れた値をもう一度代入して、両辺が等しいか確かめます。

例題と解き方

0.3 + 0.4 = [ ]。空らんにあてはまる数を書きましょう。

  1. 0.3と0.4は小数点以下の桁数が1桁なので、そのまま0.3、0.4と書きます。
  2. 0.3に同じ位の0.4をたすと0.7です。小数点はそろえた位置に書きます。
  3. 元の式の値は0.7です。表し方や四捨五入した値と、正確な計算値を区別します。
  4. この解き方の中で、数を1か所隠してみましょう。前後の式を使って隠した値を求め、もう一度入れて同じ値になるか確かめます。
  5. 空らんに0.7を入れ、元の式の両辺の値が等しいか確かめます。
例題の答えを見る0.7

よくある間違いと教え方

小数点ではなく数字の右端をそろえたり、繰り上げた1を忘れたりする

小数点に縦線を引き、同じ単位どうしをたしたか確かめます。ある位の和が10以上になったら、左の位に1を繰り上げます。

答えだけを見て、解き方の理由を省いてしまう

空らんの前後の式を一緒に読みます。示された計算の過程から必要な単位や数を求め、入れた値をもう一度代入して、両辺が等しいか確かめます。

理解度を確かめる質問

  • この問題の0.3+0.4で、それぞれの数字が表す単位を話してみようか。
  • 求めた値が答えと合っているか、別の方法で確かめられるかな。
  • 「合わせる関係図を完成させる」では、まず計算記号と位の単位のどちらを確かめたらよいかな。理由も話してみよう。
