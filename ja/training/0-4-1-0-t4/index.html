指導ガイド

わり算の筆算のまちがいを直そう

九九で商を求める

筆算の商、かけた数、ひいた数を順に確かめ、最初に間違えた計算から正しく直します。

まず確認すること

  • 九九
  • ひき算と位の値

指導の進め方

  1. 間違った解き方を上から1段階ずつ確かめます。最初にずれたところを見つけたら、その段階から計算し直し、右の欄に正しい解き方を書きます。
  2. 九九で求めた商が正しく、わられる数の一の位の上に書かれているか確かめます。
  3. わる数と商をかけた数が正しいか確かめ、その数をわられる数から正しくひいているか確かめます。
  4. 直した筆算で、わる数×商がわられる数と同じになり、ひいた結果が0になるか確かめます。

例題と解き方

24÷6の筆算で、ある子どもが24−24=1と書きました。間違いを見つけて正しく直しましょう。

  1. 子どもが書いた24−24=1が正しいか計算を確かめます。
  2. 6×4=24なので、商の4とひく数の24は正しいです。
  3. 24−24=0なので、ひき算の答え1を0に直します。
  4. 6×4=24、24−24=0なので、直した筆算は正しいです。
  5. したがって、正しく直した計算は24−24=0で、商は4、余りは0です。同じ数どうしをひいた答えを間違えて書いたことを説明します。
例題の答えを見る24−24=0に直します。商は4です。

よくある間違いと教え方

筆算の途中の計算が合っているか確かめずに進みます。

各段階でかけた数とひいた数が合っているか確かめ、最初に間違えた計算から直しましょう。

答えだけを直し、間違った途中の計算をそのままにします。

最初に間違えた段階と、直した理由を一緒に言ってもらいましょう。

理解度を確かめる質問

  • 筆算でかけた数とひいた数は、それぞれ合っているかな？
  • 24個から24個ぜんぶ取ったら、何個残る？
  • 間違いが始まった最初の計算はどこかな？

プリントの活用と丸つけ後の指導

まず、例題の24−24=1を24−24=0に直す理由を子どもが説明できるか確かめます。間違いを見つけたらすぐに答えを直すのではなく、例題のように最初に間違えた計算を指してから、理由を説明してもらいます。

次の練習

  • 最初に間違えた計算を見つけ、その後の計算まで正しく直せたか確かめた後、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 24個から24個取ると何個残るか、物や図を使って24−24=0になる理由を説明してみましょう。
