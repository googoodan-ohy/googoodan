指導ガイド

計算のまちがいを見つけて直そう

3けた×1けた

乗法九九を多桁の計算に広げ、部分積の位を正しく捉えます。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたの加法・減法、または乗法九九

指導の進め方

  1. 式を自分で計算し直し、印刷された答えと比べます。正しい答えを右の欄に書きましょう。
  2. 一の位の数字にかける数をかけます。積が10以上になったら、次の位に繰り上げる数を別に覚えておきます。
  3. 次の位の数字とかける数の積に、繰り上げた数を足します。一番大きい位まで繰り返します。
  4. かけられる数を位ごとに分け、それぞれにかけてから足した数と比べます。

例題と解き方

236×4の筆算で、ある子が一の位を6×4=25と計算し、答えを945と書きました。まちがいを見つけて、正しく直しましょう。

  1. 最初のまちがいは、一の位の計算6×4=25です。
  2. 236を位ごとに分けます：200+30+6。
  3. それぞれに4をかけて足すと944です。
  4. 一の位は6×4=24なので、4を書いて2を繰り上げます。3×4+2=14、2×4+1=9なので、236×4=944です。
  5. したがって、一の位の計算を6×4=24に直し、答えを944に直します。
例題の答えを見る944

よくある間違いと教え方

位ごとにかけたあと、繰り上げた数を足しません。

たとえば236×4は、一の位で6×4=24なので4を書いて2を繰り上げます。次は3×4+2=14なので4を書いて1を繰り上げます。百の位は2×4+1=9です。

答えだけを直して、まちがった途中の計算を残します。

最初にまちがえたところと、直した理由を一緒に説明してもらいましょう。

理解度を確かめる質問

  • 今、繰り上げた数はどこから出てきたのかな？
  • 6×4を24に直したら、十の位ではくり上がった2をどうする？
  • まちがった答えになり始めた最初の計算は、どこかな？

プリントの活用と丸つけ後の指導

まず、例題の答え944をどうしてそうなるのか、お子さんが説明できるか見ます。各位の積と繰り上げる数、または部分積の位置が合っているかを確認します。まちがった答えを見てすぐに直させず、例題のように最初にまちがえた計算を指し、その理由を説明してもらいます。

次の練習

  • 各位の積と繰り上げる数、または部分積の位置が合っているかを確かめてから、同じ条件の別の数でもう一度説明してもらいます。
  • 一人で説明するのが難しければ、例題の数をもっと小さくして、ものを使って確かめます。
