指導ガイド

絵を分けたりまとめたりして答えを書く

同じ数ずつまとめて組数を求める

1つのまとまりに入る数を決め、いくつのまとまりができるか求めます。

まず確認すること

  • 同じ数ずつまとめる
  • 九九

指導の進め方

  1. 絵の全体、まとまり、1つずつのものを指で確かめます。自分で示した結果を数や式で表し、絵と答えを照らし合わせます。
  2. 全体の数を確かめます。
  3. わる数は1つのまとまりの数、商はまとまりの数であることを確かめます。
  4. 絵の中で同じ数ずつまとめてまとまりの数を書き、かけ算で全体の数を確かめます。

例題と解き方

12個を3個ずつまとめると、何まとまりできますか。まず物を描き、3個ずつまとめて表しましょう。

  1. 全体の12個と、1つのまとまりの数3個を絵に表します。
  2. 12個を3個ずつまとめると、4まとまりできます。
  3. 3個ずつのまとまりが4つなので、3×4=12です。
  4. 12÷3=4なので、答えは4まとまりです。
例題の答えを見る4まとまり

よくある間違いと教え方

1つのまとまりの数と、まとまりの数を取り違えて言います。

答えに「まとまり」という単位を付け、場面に合うように考えましょう。

絵を数えずに、数字だけを見て答えます。

その数字が絵のどの部分から出てきたのか、指して確かめてもらいましょう。

理解度を確かめる質問

  • わる数の3は、この場面では何を表しているのかな？
  • この問題で12÷3の答えが4になる理由を、物や計算で見せてくれる？
  • それぞれのまとまりに3個ずつ入っているか、全部で何まとまりか見せてくれる？

プリントの活用と丸つけ後の指導

最初の問題「4個を2個ずつまとめると何組？」は2組です。図の4個を2個ずつ囲んで、「2組」はどれか説明してもらいましょう。次の問題も、1組に入る数と組の数を取り違えていないか見てください。

次の練習

  • 1つのまとまりの数と、まとまりの数を正しく区別できているか確かめた後、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 一人で説明するのが難しければ、例題の数をもっと小さくして、物を使って確かめます。
