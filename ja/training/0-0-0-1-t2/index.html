指導ガイド

絵の数と0〜9を結びつける

0の意味と0〜9の数の順序

絵の中の物を数え、何もないときは0と表します。枠そのものは数に入れず、絵の個数と同じ数字を結びます。

まず確認すること

  • 物を一つずつ指でさす

指導の進め方

  1. 左の絵を数え、右から同じ数の数字を探して線で結びます。ほかの絵も数えて、つなぎ間違いがないか見直します。
  2. 枠の中に物があるか見ます。物があれば一つずつ数え、一つもなければ0です。
  3. 空の枠は0と、物がある枠は数えた個数の数字と結びます。
  4. 絵を数え終わったら個数を言い、同じ数の数字と線で結びます。

例題と解き方

左の枠の中には、物が一つもありません。① 0 ② 1 ③ 2のうち、合う数字と線で結びましょう。

  1. 絵がないので、数える物はありません。
  2. 全体の個数は0個です。
  3. 右の①は答えの0と同じなので、左の問題と①を結びます。
例題の答えを見る① 0

よくある間違いと教え方

枠そのものを一つと数えてしまいます。

数えるのは枠の中の物です。一つもなければ0と答えます。

絵の形が似ているという理由だけで結びます。

絵の個数と、つないだ数字が同じか、もう一度数えて確かめます。

理解度を確かめる質問

  • 枠の中に、物は一つでもあるかな？
  • 何もない枠は、どの数字とつなげばいいかな？
  • 物が一つもないことを表す数字は、どれかな？

プリントの活用と丸つけ後の指導

絵の個数が0だとわかったら、右の0と線で結びます。線を引く前に絵の数を声に出し、引いた後に数字と合っているか見直してみましょう。

次の練習

  • 物が一つもない枠を見て、0と答えられるか確かめます。次に、物がある枠と見比べます。
  • 0がわかりにくいときは、ブロックを一つ置いてから取り去り、何も残っていないことを一緒に確かめます。
