計算手順の空らんをうめる

帯分数＋帯分数・整数部分へのくり上がりなし

分母が同じ帯分数どうしのたし算です。整数部分は1 + 2 = 3、分数部分は1/5 + 2/5 = 3/5。分数部分は1より小さいので、くり上がりません。空らんには、分数部分の分子3を書きます。

まず確認すること

  • 全体の1と、同じ大きさに分けた部分を区別する
  • 分母と分子が表す数を説明する
  • 約数・倍数、約分、仮分数と帯分数の変換

指導の進め方

  1. 分母が同じなので通分は不要です。整数部分どうし、分数部分どうしを足します。
  2. すでに書かれている数がどのような役割か確認します。
  3. 空らんを1つうめたら、前後の式が同じ値か確かめます。
  4. 整数部分は1 + 2 = 3、分数部分は1/5 + 2/5 = 3/5です。分数部分が1より小さいので、くり上がりはありません。

例題と解き方

1 1/5 + 2 2/5 = 3 + □/5

  1. 問題紙と同じ形で、整数部分と分数部分を分けます。整数部分は1 + 2 = 3です。
  2. 分数部分の分子を足すと3なので、□には3を書きます。
  3. 答えは3 3/5です。分数部分は3/5なので、くり上がりはありません。

よくある間違いと教え方

分母まで足す

分母は、1をいくつに等しく分けたかを表します。分母が同じなら、1/5などの一つ分の大きさも同じです。分子を足す前に、一つ分の大きさをそろえる理由を話してもらいます。

空らんに前にある数をそのまま入れる

解き方全体を書き直す前に、その空らんに当てはまる1つの段階のきまりを説明してもらいます。

理解度を確かめる質問

  • 分母は足さず、分子だけを足すのはどうしてかな？
  • 整数部分だけで1 + 2 = 3だね。分数部分を足すと、答えは3と4のどちらに近いかな？
  • 整数部分は3だね。1/5と2/5を足すと、□には何が入るかな？

プリントの活用と丸つけ後の指導

まず1 1/5 + 2 2/5を一緒に解きます。整数部分の3と分数部分の3/5を分けて説明できたら、同じ形の問題を数問、一人で解いてもらいます。空らんには分子を書くのか、分数全体を書くのかも見ます。

次の練習

  • 分数部分の和が1より小さい場合と、1以上になる場合を比べて解く
  • 求めた和から一方の数を引き、もう一方の元の数になるか確かめる
