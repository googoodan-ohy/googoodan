筆算の空らんをうめる

3つの小数のたし算

この活動の学習内容は「3つの小数のたし算」です。「筆算の空らんをうめる」方法で練習します。一の位どうし、小数第1位どうし、小数第2位どうしをたします。小数点以下の桁数が異なるときは、空いている位に0を書いて位をそろえます。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知っていること
  • 同じ位の数字を区別し、整数の基本的な計算ができること

指導の進め方

  1. 一の位どうし、小数第1位どうし、小数第2位どうしをたします。小数点以下の桁数が異なるときは、空いている位に0を書いて位をそろえます。
  2. 空らんがどの位にあるかを確かめます。同じ位の数字どうしをたして、繰り上がりを反映して空らんをうめたら、うめた数字で計算が合っているか確かめます。

例題と解き方

次の筆算の□にあてはまる数を書きましょう。 1.20 0.34 + 2.50 ────── 4.□4

  1. 1.2と2.5をそれぞれ1.20と2.50と書き、3つの数の小数点をそろえます。
  2. 小数第2位の和は0 + 4 + 0 = 4です。
  3. 小数第1位の和は2 + 3 + 5 = 10です。この位には0を書き、一の位に1を繰り上げます。
  4. 一の位は、繰り上げた1もたして1 + 0 + 2 + 1 = 4です。□に0を入れて得られる和4.04を、もとの式の答えと比べて確かめます。

よくある間違いと教え方

小数点ではなく数字の右端をそろえたり、繰り上がりを忘れたりする

小数点に縦線を引いて、同じ単位どうしをたしているか確かめます。ある位で、繰り上げた数もたした和が10以上になったら、その位の一の位の数字を書き、十の位の数をすぐ左の位に繰り上げます。

答えだけを見て、解き方の理由を省いてしまう

空らんがどの位にあるかを確かめます。同じ位の数字どうしをたして、繰り上がりを反映して空らんをうめたら、うめた数字で計算が合っているか確かめます。

理解度を確かめる質問

  • 1.2の2と0.34の3は、どちらも小数第1位かな？
  • □に0を入れると4.04だね。小数第1位は2＋3＋5＝10。答えの0と、くり上がる1を確かめてみよう。
  • 小数第1位をたすと2＋3＋5で10。答えには何を書いて、どこに1をくり上げる？

プリントの活用と丸つけ後の指導

まず1.2＋0.34＋2.5を一緒に筆算して、□の位を確かめましょう。あとは同じやり方で解いてもらいます。

次の練習

  • 代表例の筆算で、和4.□4の空らんをもう一度うめ、同じ条件の新しい問題2問にも取り組みます。
