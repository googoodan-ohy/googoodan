指導ガイド

絵と数字を結びつける

1〜9を数えて数字と結びつける

物一つに数詞一つを対応させ、最後に言った数が全体の個数を表すことを学びます。

まず確認すること

  • 物を一つずつ指でさす

指導の進め方

  1. 左の絵を数え、右から同じ数の数字を探して線で結びます。ほかの絵も数えて、つなぎ間違いがないか見直します。
  2. 絵を一定の方向に、一つずつ指でさします。
  3. 数えた絵には印をつけ、もう一度数えないようにします。
  4. 絵を数え終わったら個数を言い、同じ数の数字と線で結びます。

例題と解き方

左の問題：絵が7個あります。全部で何個ですか？右の選択肢：① 7 ② 8 ③ 9。合う選択肢と線で結びましょう。

  1. 絵を一つずつ数えると、最後の数は7です。
  2. 全体の個数は7個です。
  3. 右の①は答えの7と同じなので、左の問題と①を結びます。
例題の答えを見る① 7

よくある間違いと教え方

同じ絵を二度数えたり、数詞だけを暗記したりします。

一つ指すたびに数を一つ言い、数えた絵をもう一度数えないようにします。

絵の形が似ているという理由だけで結びます。

絵を数え、絵の個数とつないだ数字が合っているか確かめます。

理解度を確かめる質問

  • 全部数えたとき、最後に言った数は何かな？
  • 7個ある絵は、どの数字とつなげばいいかな？
  • 絵を数えたら、つないだ数字と同じ数になったかな？

プリントの活用と丸つけ後の指導

絵の個数が7だとわかったら、右の7と線で結びます。線を引く前に絵の数を声に出し、引いた後に数字と合っているか見直してみましょう。

次の練習

  • 一つの絵を一度ずつ数えたかを確認し、同じ条件で別の数についても説明させます。
  • 一人で説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
