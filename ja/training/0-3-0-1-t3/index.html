指導ガイド

同じ間隔で並ぶ数の組を選ぶ

2ずつ、5ずつ、10ずつ数える

2ずつ、5ずつ、10ずつ数えると、数は毎回同じ数ずつ大きくなります。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. それぞれの選択肢で隣り合う数を順番に比べます。すべての間隔を確かめてから、示されたきまりに合う選択肢を選びます。
  2. 選択肢の隣り合う数の間隔が、示されたきまりと同じか確かめます。
  3. 前の数に、きまりで示された数をたすと次の数になるか確かめます。
  4. 選んだ選択肢のすべての間隔がきまりに合う理由を話します。

例題と解き方

2ずつとび数で数えた数の組を選びましょう：① 5, 7, 9, 11 ② 5, 7, 10, 11 ③ 5, 8, 9, 11。

  1. ①は5から7、9、11へ進むたびに2ずつ大きくなります。
  2. ②は7から10へ進むときに3大きくなるので、きまりに合いません。
  3. ③は5から8へ進むときに3大きくなるので、きまりに合いません。
  4. もとの問題の条件に合う選択肢は①です。
例題の答えを見る① 5, 7, 9, 11

よくある間違いと教え方

数と数の間隔をすべて確かめません。

選択肢の隣り合う数を順番に比べ、間隔がすべて同じか確かめるよう促します。

最初の2つの数の間隔だけが合えば、その選択肢を選びます。

選択肢の最後の数まで、すべての間隔が示されたきまりに合うか確かめるよう促します。

理解度を確かめる質問

  • この問題では、いくつずつ増える並びを探すのかな？
  • 例の①では、隣り合う数の間隔が全部2か、見せてくれる？
  • 例の②は、7から10へいくつ増えているかな？ 2ずつかな？

プリントの活用と丸つけ後の指導

代表例で数の組「① 5, 7, 9, 11」を選んだ理由を説明できるか、まず確かめます。隣り合う数の間隔がすべて、示されたきまりと同じか確認できるかに注目します。選択肢ごとに合う・合わないを別々に印し、合わない選択肢では、きまりに合わないところを指してもらいます。

次の練習

  • 隣り合う数の間隔をすべて確かめているか見たあと、最初の数を変えた数の組でも同じきまりを見つけてもらいます。
  • 自分で説明するのが難しければ、小さな数の組を使い、前の数に同じ数をたして確かめます。
