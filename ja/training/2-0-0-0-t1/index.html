指導ガイド

分母を10・100・1000に変えて小数で表す

分母が10の分数を小数で表す

この活動の学習内容は「分母が10の分数を小数で表す」です。「分母を10・100・1000に変えて小数で表す」方法で練習します。小数第1位の単位は0.1、小数第2位の単位は0.01、小数第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が変わります。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知る
  • 同じ位の数字を区別し、整数の基本的な計算をする

指導の進め方

  1. 小数第1位の単位は0.1、小数第2位の単位は0.01、小数第3位の単位は0.001です。同じ数字でも、置かれた位によって表す量が変わります。
  2. 小数点以下の数字が1つなら分母10、2つなら100、3つなら1000を使います。
  3. 分母を変えるときは、同じ数を分子にもかけると同じ量を表します。
  4. まず1問を言葉で説明し、同じ方法で次の問題を解きます。

例題と解き方

7/10を分母が100の分数に直して、小数で表しましょう。

  1. 分母を100にするには、分子と分母の両方に10をかけて、7/10=70/100と表します。
  2. 70/100は0.01が70個ある数なので、0.70です。
  3. 0.70は0.7と同じ数で、0.7×100=70と確かめられます。
  4. 小数点以下の数字が1つなら分母10、2つなら100、3つなら1000を使います。
  5. 分母を変えるときは、同じ数を分子にもかけると同じ量を表します。
  6. したがって、7/10=70/100=0.7です。
例題の答えを見る70/100=0.7

よくある間違いと教え方

小数部分を1つの整数のように読んだり比べたりする

小数点の後の数字は順に読みます。大きさを比べるときは、一の位から同じ位を順に見ます。

答えだけを見て、解き方の理由を省く

まず1問を言葉で説明し、同じ方法で次の問題を解きます。

理解度を確かめる質問

  • 7/10の分母を100にするには、分子と分母にそれぞれ何をかければいいかな？
  • 求めた値が答えと一致するか、別の方法で確かめられるかな？
  • 70/100を小数で表すといくつかな？0.70と0.7は同じ数かな？

プリントの活用と丸つけ後の指導

はじめは3~5問を一緒に読み、残りは子どもが解きます。分母を変えるところで間違えたら、分子と分母に同じ数をかける理由をもう一度説明します。小数で表すところで間違えたら、分母と小数の位の値の関係を確認してから、数字を変えた問題を1問だけもう一度確かめます。速さより、同じ間違いが繰り返されているかを見てください。

次の練習

  • 代表例「7/10を分母が100の分数に直して小数で表す」を答えを隠してもう一度解き、同じ条件の新しい問題2問に取り組みます。
  • 「分母を10・100・1000に変えて小数で表す」で説明につまずいた段階だけ、もう一度練習します。数字を読むのが難しい場合は位取り表、計算が難しい場合は整数の計算に戻り、原因を見分けます。
