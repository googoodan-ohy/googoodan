指導ガイド

1つの絵に対応する式を完成させる

かけ算とわり算の関係

絵から、1組に入る個数、組の数、全部の個数を読み取り、かけ算1つとわり算2つの式を完成させます。

まず確認すること

  • 同じ数ずつまとめる
  • 九九

指導の進め方

  1. 絵を見て、1組の個数、組の数、全部の個数を数え、3つの式に書き入れます。
  2. 1組の個数×組の数が、全部の個数になるか確かめます。
  3. 全部の個数をわられる数にします。1組の個数と組の数を、わる数と商に入れかえて2つの式を作ります。
  4. 完成した3つの式のそれぞれの数が、絵のどの部分を表しているか確かめます。

例題と解き方

絵には3個ずつのまとまりが4つあります。絵を見て、かけ算の式と2つのわり算の式を完成させましょう。

  1. 1組に3個ずつ、4組あるので、全部で12個です。
  2. かけ算の式は3×4=12です。
  3. わり算の式は12÷3=4と12÷4=3です。
  4. 3つの式が、絵のまとまりの数と全体の数を表しているか確かめます。
例題の答えを見る3×4=12, 12÷3=4, 12÷4=3

よくある間違いと教え方

1組に入る個数、組の数、全部の個数を取り違えて式を書きます。

絵から3つの数をそれぞれ指し、全体の数をかけ算の積とわり算のわられる数に書いてもらいましょう。

絵のまとまりの数と全体の数を確かめずに式を書きます。

絵から見つけた数が、かけ算の式と2つのわり算の式にどのように使われているか説明してもらいましょう。

理解度を確かめる質問

  • わり算の式12÷3=4の3と4は、絵の何を表しているのかな？
  • 同じ絵を12÷4=3とも表せる理由を説明してくれる？
  • 3は1組の個数、4は組の数だね。12は何の数かな？

プリントの活用と丸つけ後の指導

まず、例題で完成させた3つの式が、絵のまとまりの数と全体の数を表しているか確かめます。絵から見つけた数を、かけ算の式と2つのわり算の式に合うように書けているか確かめます。

次の練習

  • 絵の1つのまとまりの数、まとまりの数、全体の数を3つの式に正しく表せているか確かめた後、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 一人で説明するのが難しければ、例題の数をもっと小さくして、物を使って確かめます。
