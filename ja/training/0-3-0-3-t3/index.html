指導ガイド

かけ算の式に合う並びを完成させる

並びとかけ算の式を結びつける

並びの1列の個数と列の数を区別し、かけ算の式に結びつけます。

まず確認すること

  • 各位の数字が表す数を理解する
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. まず、1問の並びを言葉で説明しながらかきます。その後は、お子さん自身で並びをかき、式の2つの数が図に合うように表されているか確認してもらいます。
  2. かけ算の式の1つ目の数を1列の個数として、2つ目の数を列の数として表し、並びをかきます。
  3. どの列も個数が同じで、列の数がかけ算の式に合っているか確認します。
  4. かいた並びの全部の個数を求め、かけ算の式の答えと比べます。

例題と解き方

3×4に合う並びをかき、全部の個数を確かめましょう。

  1. 3×4は、1列に3個ずつ、4列並べた図で表せます。
  2. 各列に点を3個ずつかき、全部で4列にします。
  3. かいた点の数は3+3+3+3=12なので、全部で12個です。
  4. 図に4列あり、各列に3個ずつあるか確認します。
例題の答えを見る● ● ● ● ● ● ● ● ● ● ● ● 1列に点が3個ずつ、4列あり、全部で12個です。

よくある間違いと教え方

かけ算の式の2つの数が表す1列の個数と列の数を入れ替えてかきます。

かけ算の式の1つ目の数が1列の個数に、2つ目の数が列の数に対応するようにかいているか確認してください。

並びをかかず、計算の答えだけを書きます。

かけ算の式に合う図をかく問題だと確認し、1列の個数と列の数を言いながらかかせてください。

理解度を確かめる質問

  • 式の2つの数は、図の中でそれぞれ何を表しているのかな？
  • 例で3×4の答えが12になる理由を、物や計算で見せてくれる？
  • 図の列の数と1列の個数は、かけ算の式と合っているかな？

プリントの活用と丸つけ後の指導

代表的な例で、3×4に合う並びをかき、全部で12個になる理由を説明できるか見ます。列の数と1列の個数が、式の2つの数に合っているか確認します。

次の練習

  • 実際の図で、まとまりの大きさとまとまりの数を区別できるか確認した後、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 3×4の3個ずつ4段の並びを描き、図と式の両方が12を表すか確かめます。
