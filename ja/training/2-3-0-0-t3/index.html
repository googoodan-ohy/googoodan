変換の手順の空らんをうめる

小数の積を整数の積と結びつける

この活動の学習内容は「小数の積を整数の積と結びつける」です。「変換の手順の空らんをうめる」方法で練習します。まず整数の積で計算し、2つの数の小数点以下の桁数の合計と同じ桁数の小数部分を積にとります。数字が足りないときは左に0を補います。

まず確認すること

  • 小数第1位・第2位・第3位の単位を知っている
  • 同じ位の数字を区別し、整数の基本的な計算ができる

指導の進め方

  1. まず整数の積で計算し、2つの数の小数点以下の桁数の合計と同じ桁数の小数部分を積にとります。数字が足りないときは左に0を補います。
  2. 空らんの前後の式を一緒に読みます。示された計算の手順から必要な単位や数を求め、うめた値をもう一度代入して両辺が等しいか確かめます。

例題と解き方

0.71×0.03=(71×3)÷10000=[ ]÷10000=[ ]。□にあてはまる数を書きましょう。

  1. 0.71は71/100、0.03は3/100です。
  2. 整数の積は71×3=213です。
  3. 213を10000で割ると0.0213になります。小数点以下は4桁です。
  4. 空らんには213と0.0213が入ります。
例題の答えを見る213, 0.0213

よくある間違いと教え方

2つの数の小数点の位置をそろえてかけたり、積の小数点の位置を1桁間違えたりする

たし算とかけ算の方法を区別します。0.6×0.5は6×5を100で割った値です。

答えだけを見て、解き方の理由を省いてしまう

空らんの前後の式を一緒に読みます。示された計算の手順から必要な単位や数を求め、うめた値をもう一度代入して両辺が等しいか確かめます。

理解度を確かめる質問

  • 0.71と0.03を100分の数で表すと、分子はそれぞれいくつ？
  • 71×3の積を何で割ればいいかな？
  • 213÷10000を小数で書くと、いくつになる？

プリントの活用と丸つけ後の指導

最初は3～5問を一緒に読み、残りはお子さんが解きます。変換の手順の空らんをうめる問題を間違えたら、整数の積をいくつで割るかをもう一度説明し、数字を変えた問題を1問だけ解いて確かめます。速さより、同じ間違いを繰り返していないかを見てください。
