指導ガイド

同じ数ずつ分けて、1皿分の数を求める

等分して1つ分を求める

全体を人数や皿の数に合わせて同じ数ずつ分け、1人分や1皿分の数を求めます。

まず確認すること

  • 同じ数ずつまとめる
  • 九九

指導の進め方

  1. 絵の全体、まとまり、1つずつのものを指で確かめます。自分で示した結果を数や式で表し、絵と答えを照らし合わせます。
  2. 全体の数を確かめます。
  3. わる数は人数や皿の数、商は1人や1皿に分けられる数であることを確かめます。
  4. 絵を使って分けて商を書き、かけ算で全体の数を確かめます。

例題と解き方

12個を3皿に同じ数ずつ分けると、1皿に何個になりますか。まず物を描き、皿ごとに同じ数ずつ分けて表しましょう。

  1. 全体の物は12個で、分けて入れる皿は3皿です。
  2. 12個を3皿に1個ずつ順番に置き、同じ数ずつ分けます。
  3. 1皿に4個ずつ入るので、12÷3=4です。
  4. 3皿に4個ずつ入れた全体の数が4×3=12になるか確かめます。
例題の答えを見る4個

よくある間違いと教え方

分ける人数や皿の数と、1人分や1皿分の個数を取り違えます。

絵の中で分ける場所の数と、1か所に分けられる数をそれぞれ指し、答えに合った単位を付けましょう。

絵を数えずに、数字だけを見て答えます。

その数字が絵のどの部分から出てきたのか、指して確かめてもらいましょう。

理解度を確かめる質問

  • 12個を、何枚のお皿に分けるんだったかな？
  • 12個を3枚のお皿に分けて、1枚に4個ずつになるところを見せてくれる？
  • 皿ごとに同じ数ずつ分けたか、どうやって確かめられるかな？

プリントの活用と丸つけ後の指導

まず、12個を3枚のお皿に分ける例で、1皿分が4個になる理由を聞きます。このページの3問は、分ける皿の数と1皿分の個数を区別できるか見ながら進めます。迷ったら、おはじきを1個ずつ配って確かめましょう。

次の練習

  • わる数と、1か所に分けられる商を正しく区別できているか確かめた後、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 一人で説明するのが難しければ、例題の数をもっと小さくして、物を使って確かめます。
