指導ガイド

まとまりの数と全体の数を書く

10個ずつまとめて数える

10個ずつのまとまりの数と残ったばらの数が分かれば、ものを1つずつ数えなくても全体の個数を求められます。

まず確認すること

  • 10まで数える
  • 10のまとまりとばら

指導の進め方

  1. まず1問を言葉で説明しながら解きます。その後は、お子さんが自分で計算し、答えが表す数や個数を読み上げるようにします。
  2. 絵のものを10個ずつ囲んでまとめます。
  3. まとまりの数を数え、1つのまとまりが10個という意味を言葉にします。
  4. まとまりの数×10にばらの数を足して、全体の個数を求めます。

例題と解き方

10個ずつのまとまりが2つと、ばらが5個あります。まず、ものやまとまりを描いて、まとまりの数とばらの数を書き、全部でいくつか求めましょう。

  1. 10個ずつのまとまり2つは、10+10=20個です。
  2. 20個にばら5個を足すと、20+5=25です。
  3. したがって、まとまり2つ、ばら5個で、全部で25個です。
例題の答えを見るまとまり2つ、ばら5個、全部で25個

よくある間違いと教え方

まとまりの数と全体の個数を混同します。

まとまりの数は2、ばらの数は5、全体の個数は25と対応させて区別してください。

計算の答えだけを書き、解き方の理由を説明しません。

最初の2問は、計算した理由を短く言葉にさせてください。

理解度を確かめる質問

  • まとまりはいくつで、ものは全部でいくつかな？
  • 例題で2×10+5の答えが25になる理由を、ものや計算で見せてくれる？
  • この数を、ものや位ごとのまとまりで表すとどうなるかな？

プリントの活用と丸つけ後の指導

まず、例題の答え25をお子さんが説明できるか見ます。注目する点は、10個ずつのまとまりの数と残ったばらの数を区別できるかです。最初の2問は解き方を言葉にさせ、その後の3問は一人で解かせます。同じ間違いが続く場合は、計算量を増やさず、問題の表し方を絵やものに変えます。

次の練習

  • まとまりの数とばらの数を区別できるか確かめた後、同じ条件で数を変えてもう一度説明させます。
  • 一人で説明するのが難しければ、例題の数をより小さな数に変え、ものを使って確かめます。
