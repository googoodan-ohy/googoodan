指導ガイド

絵とまとまりの表し方を結びつける

10個ずつまとめて数える

10個ずつのまとまりの数と残ったばらの数が分かれば、ものを1つずつ数えなくても全体の個数を求められます。

まず確認すること

  • 10まで数える
  • 10のまとまりとばら

指導の進め方

  1. 左の絵のまとまりの数とばらの数を数え、右の選択肢から同じまとまりの表し方を探します。線を引く前に、まだ使っていない選択肢も確かめ、同じ選択肢を重ねて使わないようにします。
  2. 絵のものを10個ずつ囲んでまとめます。
  3. まとまりの数を数え、1つのまとまりが10個という意味を言葉にします。
  4. 残ったばらの数を数え、まとまりの数とばらの数がどちらも同じ選択肢と結びつけます。

例題と解き方

左の絵には、10個ずつのまとまりが6つと、ばらが5個あります。右の選択肢：① まとまり6つ、ばら5個 ② まとまり6つ、ばら6個 ③ まとまり7つ、ばら5個。正しい選択肢と線で結びましょう。

  1. 絵には、10個ずつまとめたものが6つあります。
  2. まとまりの外に残ったばらは5個です。
  3. 右の①「まとまり6つ、ばら5個」が絵と一致するので、左の絵と①を結びます。
例題の答えを見る① まとまり6つ、ばら5個

よくある間違いと教え方

まとまりの数と全体の個数を混同します。

まとまりの数は6、ばらの数は5、全体の個数は65と対応させて区別してください。

絵の形が似ているという理由だけで結びつけます。

絵のまとまりの数とばらの数が、選択肢の表し方とそれぞれ同じか説明させてください。

理解度を確かめる質問

  • まとまりはいくつで、ものは全部でいくつかな？
  • 10個のまとまりはいくつ？ 外に残っているのは何個かな？
  • 結んだ両方が同じ数だと、どうして分かるのかな？

プリントの活用と丸つけ後の指導

左の絵のまとまり6つとばら5個を、それぞれ指で数えてもらいます。右の候補もまとまりとばらを別々に読み、両方の数が合う①と線で結びましょう。

次の練習

  • まとまり6つとばら5個を正しく結べたら、ばらが6個の絵との違いも説明してもらいましょう。
  • 一人で説明するのが難しければ、例題の数をより小さな数に変え、ものを使って確かめます。
