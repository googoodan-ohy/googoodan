指導ガイド

基準量と比べる量の空らんをうめる

何倍の意味

何倍とは、基準の量をその回数分集めた大きさです。

まず確認すること

  • ものの数を数え、同じ数ずつにまとめる
  • 1けたのたし算・ひき算、または九九

指導の進め方

  1. 文を読み、空らんが基準の量、何倍かを表す数、比べる量のどれを表すか確かめます。空らんをうめたあと、文全体が正しいか確かめます。
  2. 与えられた数が、基準の量、何倍かを表す数、比べる量のどれかを見分けます。
  3. 絵やものを使って場面を表し、どの計算が合うか話します。
  4. 求めた数を空らんに書き、基準の量と何倍かを表す数、比べる量の関係が合っているか言葉で説明します。

例題と解き方

空らんに合う数を書きましょう：3の4倍は□。

  1. 3の4倍は、3を4回たした数だと確かめます。
  2. 3+3+3+3=12なので、空らんには12を書きます。
  3. 3×4=12か確かめます。
  4. 空らんに12を入れ、「3の4倍は12」が正しいか確かめます。
例題の答えを見る12

よくある間違いと教え方

基準の量と比べる量の関係を見ずに、与えられた2つの数をたします。

空らんが基準の量、何倍かを表す数、比べる量のどれかをまず言ってもらい、その役割に合うかけ算やわり算を選ぶよう促します。

空らんの前と後ろの数を、いつもたします。

空らんが何を表すか、まず言ってもらってから計算を選びます。

理解度を確かめる質問

  • 「3の4倍は12」で、3と4はそれぞれ何を表しているのかな？
  • 例の3×4が12になる理由を、ものや計算を使って見せてくれる？
  • 空らんに求めた数を入れて文全体を読むと、正しいかな？

プリントの活用と丸つけ後の指導

代表例の答え12を説明できるか、まず確かめます。基準の量と何倍かを表す数を見分けられるかに注目します。空らんを1つうめたあと、文全体をもう一度読んでもらいます。答えが合っていても、どの数を求めたのか理由を確かめます。

次の練習

  • 空らんが基準の量、何倍かを表す数、比べる量のどれかを見分けられるか確かめたあと、同じ条件で別の数を使ってもう一度説明してもらいます。
  • 「3の4倍は□」を3+3+3+3に直し、□に12を入れて文を読み直します。
