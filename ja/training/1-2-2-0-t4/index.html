指導ガイド

計算が合っているか確かめよう

真分数−真分数・一方の分母がもう一方の倍数

真分数−真分数で、一方の分母がもう一方の倍数である場合を扱う指導資料です。分母の異なる分数は、通分して1つ分の大きさをそろえてから計算します。まちがいを見つける活動では、答えだけを教えず、最初に値が変わった行を子どもが指摘できるようにします。正しくできている部分は残し、その箇所から計算し直してもらいます。

まず確認すること

  • 1つの全体と、同じ大きさに分けた部分を区別する
  • 分母と分子が表す数を説明する
  • 約数・倍数、約分、仮分数・帯分数の変換

指導の進め方

  1. 2つの分母を確認し、大きい方の分母にそろえて通分します。
  2. まず元の計算を別に行い、答えのおよその大きさを予想します。
  3. まちがった行を見つけ、なぜ値が変わったのかを言葉で説明してもらいます。
  4. 代表的な例題のまちがいの原因と、直した結果を子どもにもう一度説明してもらいます。

例題と解き方

まちがった計算：5/6 − 1/3 = 2/3。まちがいを直しましょう。

  1. 分母をそろえず分子だけを引いたため、2/3になりました。通分すると、5/6 − 2/6 = 3/6 = 1/2です。
  2. 分母6と3の公倍数である6に通分すると、1/3 = 2/6です。
  3. 分母を同じままにして分子どうしをひくと、5/6 − 2/6 = 3/6です。
  4. 3/6を約分すると1/2です。
  5. 5/6 − 1/3 = 1/2
  6. 逆算で確かめると、1/2 + 1/3 = 3/6 + 2/6 = 5/6です。
例題の答えを見る1/2

よくある間違いと教え方

分母もひく

分母は、もとの大きさをいくつに等分したかを表します。通分して、1つ分の大きさをそろえてから分子を引きます。

まちがった答えだけを消して、理由を確かめない

計算のきまりをまちがえて使った最初の段階と、単純な計算ミスを区別して示します。

理解度を確かめる質問

  • 1/3と同じ大きさで、分母が6の分数は何かな？
  • 1/3を分母が6の分数にすると、分子はいくつになるかな？
  • 5/6 − 1/3は、本当に2/3になるかな？分母を6にそろえてみよう。

プリントの活用と丸つけ後の指導

最初は3〜5問を一緒に見て、同じまちがいが繰り返されていないか確認します。まちがいを見つける活動では、答えだけを教えず、最初に値が変わった行を子どもが指摘できるようにします。正しくできている部分は残し、その箇所から計算し直してもらいます。分母をそろえる理由の説明があいまいな場合は、問題数を増やさず、該当する考え方の図や変換の練習に戻ります。

次の練習

  • 通分だけが必要な問題と、通分とくり下がりの両方が必要な問題を比べる
  • 求めた差にひいた数をたし、分母をそろえて確かめる
