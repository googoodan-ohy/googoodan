指導ガイド

計算結果と等しい分数を結びつける

真分数＋真分数・和が1未満

分母が同じ分数のたし算をして、計算結果と等しい分数を線で結ぶページです。分母はそのままにして、分子を足します。

まず確認すること

  • 全体1つと、同じ大きさに分けた部分を区別する
  • 分母と分子が表す数を説明する
  • 約数・倍数と約分、仮分数・帯分数の変換

指導の進め方

  1. 2つの分数の分母が同じか確認してから、分子どうしを足し、分母はそのままにします。
  2. 左側の項目を1つ選び、値を先に求めます。
  3. 同じ値になる右側の項目を見つけ、結びつけた根拠を説明してもらいます。
  4. 2/6 + 1/6 = 3/6です。約分すると1/2なので、右の1/2と結びます。

例題と解き方

左の計算「2/6 + 1/6」と同じ値の分数を、右から見つけて結びましょう。

  1. 2/6 + 1/6 = 3/6です。
  2. 3/6を約分すると1/2になります。
  3. 右の1/2と同じ大きさなので、そこに結びます。
例題の答えを見る1/2に結ぶ

よくある間違いと教え方

分母も足す

分母は部分の大きさを表します。分子を計算する前に、2つの部分の大きさが同じか説明してもらいます。

分子や数字の形だけが同じ項目を結ぶ

必要に応じて、約分・通分や図の部分の数を使って、2つの値が等しいことを確認します。

理解度を確かめる質問

  • 同じ分母は足さずに、分子だけを足すのはどうしてかな？
  • 求めた和が1より大きいか小さいか、分子と分母を使って確かめてみようか？
  • 2/6 + 1/6を計算して約分すると、右のどの分数と同じかな？

プリントの活用と丸つけ後の指導

右の分数が約分された形なら、左の計算結果を約分してから比べましょう。

次の練習

  • 和が1より小さい場合と1以上の場合を並べて解く
  • 求めた和から一方の項を引き、もう一方の項に戻るか確かめる
