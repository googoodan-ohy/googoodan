指導ガイド

数と同じ数だけ色をぬる

1〜9を数えて数字と結びつける

示された数字を読み、その数だけ印を自分でつけます。絵を数えて数字を書く活動とは反対に、数字を出発点にして、正しい個数の絵を作ります。

まず確認すること

  • 物を一つずつ指でさす

指導の進め方

  1. 示された数を先に読みます。
  2. 一つぬるごとに数を一つずつ数え、書いてある数になったら止めます。
  3. できた印をもう一度数え、示された数と同じか確かめます。

例題と解き方

数の7を見て、その数だけ点をかきましょう。

  1. 点を一つかくたびに、1から順に数えます。
  2. 7で止めます。できた点をもう一度数えて、7個あるか確かめます。
例題の答えを見る点7個

よくある間違いと教え方

数を読んだ後に印を一つ多くつけたり、目標の数に達する前に止めたりします。

印を一つつけるたびに、数詞を一つだけ言います。示された数を言ったら、新しい印をつけないようにします。

できた印を数え直さず、目標と違う個数のままにします。

完成したら印を一つずつ指でさして数え直し、数字と同じになったら終わりにするよう促してください。

理解度を確かめる質問

  • どの数字を読んで、印をつけたのかな？
  • 7個作るには、何番目の印で止めればいいかな？
  • できた印をもう一度数え直すと、示された数と同じかな？

プリントの活用と丸つけ後の指導

数字の7を見せて、自分で点を7個つけた後、もう一度数えさせます。少なかったり多かったりしたら、最初から消すのではなく、いくつ足したり消したりすればよいか考えさせます。

次の練習

  • 一つの絵を一度ずつ数えたかを確認し、同じ条件で別の数についても説明させます。
  • 一人で説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
