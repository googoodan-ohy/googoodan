公約数と最大公約数

公約数は、2つの数の約数の両方にある数で、その中で最も大きい数が最大公約数です。

まず確認すること

  • 九九
  • 割り切れるわり算

指導の進め方

  1. 各行の見出しを読み、二つの数の約数と公約数の欄を区別します。公約数は両方の数を割り切るか確かめ、最大公約数の欄には公約数のうち最も大きい数を書きます。
  2. 12と18の約数をそれぞれ書き出し、両方にある数に印を付けます。
  3. 共通する数を探す問題では、両方の一覧にあるか確認します。
  4. 公約数をすべて書いたら、最大公約数を求める欄には、その中でいちばん大きい数を書きます。

例題と解き方

12と18の公約数と最大公約数を求めましょう。

  1. 12の約数：1, 2, 3, 4, 6, 12。
  2. 18の約数：1, 2, 3, 6, 9, 18。
  3. 公約数は1, 2, 3, 6で、最も大きい数は6です。
例題の答えを見る公約数 1, 2, 3, 6; 最大公約数 6

よくある間違いと教え方

約数と倍数を取り違えたり、最大公約数と最小公倍数を混同したりします。

12÷3＝4なので3は12の約数、12×3＝36なので36は12の倍数です。わり算とかけ算の式で違いを確かめます。

隣のます目の答えをそのまま書きます。

16の約数と52の約数は別々に考えます。隣の欄を写さず、それぞれの数を割り切るか確かめてもらいましょう。

理解度を確かめる質問

  • 書いた数で、12も18も割り切れるかな？
  • 6で12を割ると2だね。18も6で割り切れるかな？
  • 公約数の欄に入れた数で、二つの数をどちらも割り切れるかな？

プリントの活用と丸つけ後の指導

12と18の約数を書き出し、公約数の1、2、3、6を見つけてもらいます。表では、約数の欄と公約数の欄を区別してうめます。公約数の欄を書いたら、両方の数を割り切るか確かめ、最大公約数の欄には6を書きます。

次の練習

  • 12と18で見つけた公約数が、両方の数を割り切ることを式で確かめます。次は、別の二つの数でも公約数を探してもらいます。
  • 一人で説明するのが難しければ、代表例の数をもっと小さくして、物を使って確かめます。
