指導ガイド

まちがった計算の手順を直す

3けたのたし算（くり上がりなし）

一の位から百の位まで、同じ位どうしを順にたします。くり上がりはありません。

まず確認すること

  • 一の位・十の位・百の位の位取り
  • 1けたの数のたし算

指導の進め方

  1. まちがった解き方を上から1段階ずつ確かめてもらいます。最初にまちがえたところを見つけたら、その段階から計算し直し、右の欄に正しい解き方を書きます。
  2. 2つの数が表す個数、または同じ位の数字を確かめます。
  3. 各位の2つの数字をたし、その位に和を書きます。
  4. 和から一方の数を引くと、もう一方の数になるか確かめます。

例題と解き方

243 + 325を計算しましょう。ある子どもが答えを「569」と書きました。まちがいを直しましょう。

  1. 書かれた答えをそのまま信じず、もとの条件と計算を確かめます。
  2. 一の位：3+5=8。8を書きます。
  3. 十の位：4+2=6。6を書きます。
  4. 百の位：2+3=5。5を書きます。
  5. 和は568です。568−325=243となることを確かめます。
  6. したがって、直した答えは568です。どの位、またはどの関係でまちがえたか話します。
例題の答えを見る568

よくある間違いと教え方

2つのまとまりの境目を数えるときに物を1つ数え忘れたり、同じ位の数字をまちがえてたしたりします。

2つの部分をそれぞれ確かめてから、合わせて数えてみましょう。けた数の多い計算では、同じ位の数字どうしを対応させます。

答えだけ直して、まちがった途中の計算を残します。

最初にまちがえた段階と、直した理由を一緒に話してもらいましょう。

理解度を確かめる質問

  • 和から最初の数を引くと、どんな数が残るはずかな？
  • 569のどの位がまちがっているかな？ 3+5から確かめてみよう。
  • まちがった答えになり始めた最初の計算は、どこかな？

プリントの活用と丸つけ後の指導

まず、例の答え568を子どもが説明できるか確かめます。2つの部分を合わせた数と全体が同じかどうかに注目します。まちがった答えをすぐに直させず、例のように最初にまちがえた計算を指し示してから、理由を説明してもらいます。

次の練習

  • 2つの部分を合わせた数と全体が同じか確かめたあと、同じ条件の別の数でもう一度説明してもらいます。
  • 自分だけで説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
