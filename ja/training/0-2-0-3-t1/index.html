たし算とひき算の関係

ひき算で見つけた部分に、ひいた部分をたすと全体になります。

まず確認すること

  • 各位の数字が表す数の大きさを理解する
  • 1けたのたし算・ひき算

指導の進め方

  1. まず1問を言葉で説明しながら解きます。その後はお子さんがたし算とひき算の関係を使って□を埋め、完成した式を読むようにします。
  2. たし算の式からたす2つの数と和を見つけ、組になるひき算の式の最初に和があるか確かめます。
  3. 絵や物を使って、2つの部分を合わせると全体になり、全体から一方の部分をひくともう一方の部分が残る関係を表します。
  4. たし算の式の2つの数と和の関係を使って、ひき算の式の□を埋め、完成した式を読みます。

例題と解き方

2+4=6と組になるひき算の式6−2=□を完成させましょう。

  1. 6から2をひくと4なので、□に4を書きます。
  2. 4+2=6で確かめます。
例題の答えを見る4

よくある間違いと教え方

たし算の式の和からひかず、たす2つの数どうしをひきます。

たし算の答えの6から2をひくと、もう一方の数の4が残ることを、おはじきで確かめます。

計算の結果だけを書き、解き方の理由を説明しません。

最初の2問は、計算した理由を短く話させましょう。

理解度を確かめる質問

  • 2＋4＝6の2、4、6は、ひき算の式ではどこにあるかな？
  • 4個に2個足すと6個になるね。6個から2個取ると、何個残る？
  • 6個のおはじきを、2個と残りの4個に分けてみよう。

プリントの活用と丸つけ後の指導

6−2の答えが4になる理由を聞いてみます。4＋2＝6と確かめられたら、次の問題は自分で解いてもらいましょう。同じ間違いが続くときは、おはじき6個から2個を取り除いて、残りを数えます。

次の練習

  • 2＋4＝6から6−2＝4を書いたら、6−4も書いて2になるか確かめましょう。
  • 自分で説明するのが難しければ、例の数をもっと小さい数に変えて、物を使って確かめます。
