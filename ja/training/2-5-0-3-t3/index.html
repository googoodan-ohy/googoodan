指導ガイド

逆の計算で空らんを求めて確かめる

空らんにあてはまる数を求める・小数の四則計算

この活動で学習する内容は「空らんにあてはまる数を求める・小数の四則計算」です。「逆の計算で空らんを求めて確かめる」方法で練習します。計算する前に、計算記号と空らんの位置を確かめます。たし算・ひき算では位をそろえ、かけ算・わり算では単位がどのように変わるか考えます。

まず確認すること

  • 小数第1位から第3位までの位の大きさを理解している
  • 同じ位の数字を区別し、整数の基本的な計算ができること

指導の進め方

  1. 計算する前に、計算記号と空らんの位置を確かめます。たし算・ひき算では位をそろえ、かけ算・わり算では、小数点の位置や答えの大きさに気をつけます。
  2. 与えられた式で、空らんの位置と計算記号を確かめます。逆の計算で空らんに入る数を求め、入れた数をもう一度あてはめて、式が成り立つか確かめます。

例題と解き方

□ − 1.2 = 2.3で、逆の計算を使って□を求め、確かめましょう。

  1. □ − 1.2 = 2.3で、ひかれる数を求めるには、差とひく数をたします。
  2. 2.3 + 1.2 = 3.5なので、空らんは3.5です。
  3. もとの式に入れると、3.5 − 1.2 = 2.3です。
  4. ひき算と逆の関係にあるたし算を使って空らんを求め、求めた数をもとの式に入れて確かめます。
  5. 空らんに3.5を入れると、3.5 − 1.2 = 2.3となるので正しいです。
例題の答えを見る3.5

よくある間違いと教え方

前の問題の計算方法を次の問題にもそのまま使ってしまう

それぞれの式の計算記号を指でさし、計算方法を一文で言ってから解きます。

答えだけを見て、解き方の理由を省いてしまう

与えられた式で、空らんの位置と計算記号を確かめます。逆の計算で空らんに入る数を求め、入れた数をもう一度あてはめて、式が成り立つか確かめます。

理解度を確かめる質問

  • □ − 1.2 = 2.3で、空らんを求めるにはどんな計算をすればいいかな？
  • 求めた数が答えと合っているか、別の方法で確かめられるかな？
  • 「逆の計算で空らんを求めて確かめる」とき、最初に確かめるのは計算記号かな、それとも位の単位かな？理由も話してみよう。

プリントの活用と丸つけ後の指導

□−7.5＝1.6を解いたら、答えを元の式に入れて9.1−7.5＝1.6になるか確かめてみましょう。

次の練習
