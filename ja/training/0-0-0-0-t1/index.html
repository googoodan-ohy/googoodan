指導ガイド

1〜9を数えて数を書く

整数の個数を数えて表す（1〜9）

物一つに数詞一つを対応させ、最後に言った数が全体の個数を表すことを学びます。

まず確認すること

  • 物を一つずつ指でさす

指導の進め方

  1. 絵全体、まとまり、一つ一つを手で指します。自分で印をつけた結果を数や式に表し、絵と答えを照らし合わせます。
  2. 絵を一定の方向に、一つずつ指でさします。
  3. 数えた絵には印をつけ、もう一度数えないようにします。
  4. 最後に言った数が、絵の個数です。数字で書きましょう。

例題と解き方

点を左から一つずつ指でさして数え、全体の個数を書きましょう。

  1. 点を一つ指すたびに、数詞を一つだけ言います。
  2. 最後に言った数は7なので、全部で7個です。
例題の答えを見る7

よくある間違いと教え方

同じ絵を二度数えたり、数詞だけを暗記したりします。

指でさす速さと数を言う速さを合わせてください。何もない絵は0と言います。

絵を数えず、数字だけを見て答えます。

その数字が絵のどの部分から出たのか、指でさして説明させてください。

理解度を確かめる質問

  • 全部数えたとき、最後に言った数は何かな？
  • 例の答えが7になる理由を、物や計算で見せてくれる？
  • この数を物や位ごとのまとまりで表すと、どうなるかな？

プリントの活用と丸つけ後の指導

例の答えの7を説明できるか、まず確認します。一つの絵を一度ずつ数えたかを見てください。最初の2問は解き方を説明させ、その後の3問は一人で解かせます。同じ間違いが続く場合は、計算量を増やさず、問題を絵や物で表します。

次の練習

  • 一つの絵を一度ずつ数えたかを確認し、同じ条件で別の数についても説明させます。
  • 一人で説明するのが難しければ、例の数をもっと小さくして、物を使って確かめます。
