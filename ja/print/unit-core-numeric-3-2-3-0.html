指導ガイド

小学3年生 わり算とあまりの基本

3けた÷1けたでは、左から商を立てて筆算し、あまりが出る場合はわる数より小さいことを確かめます。かけ算とあまりを合わせると、わられる数に戻ります。

3けた÷1けたの筆算では、百の位と十の位を見て商を立て、次の位の数を下ろして計算します。あまりはわる数より小さくなり、わる数×商+あまりで元の数に戻ります。

まず確認すること

  • 数を読み、数量を一つずつ数えられること。
  • 九九を使ったわり算と、二けた÷一けたの筆算ができること。

指導の進め方

  1. あまりのあるわり算は、わる数の段で、わられる数をこえないいちばん大きい積を探します。
  2. 8÷□=4は、□×4=8と考えます。□は2で、8÷2=4と確かめられます。
  3. 171÷9は、百の位の1だけでは9でわれないので、十の位の7と合わせて17十を9でわります。17十の中に9十は1つ。商の1を十の位にたて、1×9=9、17−9=8十です。
  4. 次に一の位の1をおろすと81になります。81÷9=9なので、商の9を一の位にたてます。答えは19です。

例題と解き方

29÷4の商とあまりを求めましょう。

  1. 4の段で29をこえないいちばん大きい積は28です。
  2. 4×7=28なので商は7です。
  3. 29−28=1であまりは1。1はわる数の4より小さいので、答えは商7、あまり1です。
例題の答えを見る
商7、あまり1

よくあるつまずき

あまりがわる数以上のまま答えにしてしまうことがあります。

あまりがわる数以上なら商を一つ増やして計算し直します。答えは「わる数×商+あまり」で元の数になるか確かめます。

あまりのあるわり算で、答えにあまりを書き忘れることがあります。

商とあまりを分けて書き、わる数×商+あまりがわられる数になるか確認します。

おうちの方へ

  • 171÷9の商は、どの位から書く？
  • 19÷4のあまり3は、4より小さい？

練習のすすめ方

答えが出たら「わる数×商+あまり」を計算します。19÷4=4あまり3なら、4×4+3=19に戻るか確かめましょう。

次のステップ

  • 19個のおはじきを4個ずつの組にして、4組できて3個残ることを確かめます。
