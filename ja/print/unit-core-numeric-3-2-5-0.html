指導ガイド

小学4年生 仮分数・帯分数と大小

図を分数で表し、仮分数を帯分数に直して、同分母の分数の大小を比べます。

等分した数を分母、色のついた部分を分子にして図を分数で表します。仮分数は商とあまりを使って帯分数にし、分母が同じ分数は分子を比べます。

まず確認すること

  • 分子と分母が表すものを理解している
  • 同じ分母の分数の大小を比べられる

指導の進め方

  1. 図では、全体をいくつに等しく分けたかを分母、色のついた部分の数を分子にします。
  2. 仮分数は分子を分母で割り、商を整数部分、あまりを分子として帯分数にします。
  3. 同じ分母の分数は、分子の大きさを比べます。
  4. 帯分数に直した数を元の仮分数に戻して、図や計算で確かめます。

例題と解き方

17/4を帯分数で表しましょう。

  1. 17÷4＝4あまり1です。
  2. 商の4を整数部分、あまりの1を分子にし、分母の4はそのままにします。
例題の答えを見る
4と1/4

2/5と4/5の大小を比べましょう。

  1. 分母が同じなので、分子の2と4を比べます。
  2. 2は4より小さいので、2/5＜4/5です。
例題の答えを見る
2/5＜4/5

よくあるつまずき

仮分数を帯分数にするとき、あまりを整数部分にする

商が整数部分、あまりが分子で、元の分母は変わらないと確認します。

同分母の分数で分母の大きさを比べる

分母が同じなら一つ分の大きさは同じなので、分子を比べます。

おうちの方へ

  • 図をいくつに等しく分けて、色の部分はいくつ分かな？
  • 4分の1が17個あります。4個で1になるまとまりは何組できて、4分の1が何個余るかな？
  • 分母が同じ二つの分数では、どこを比べる？

練習のすすめ方

図から分数を表すときは、等分した数と色のついた数を別々に数えます。仮分数は割り算の商とあまりを書き、大小は分母が同じか確かめてから比べましょう。

次のステップ

  • 図の分数を仮分数や帯分数で表し直す
  • 分母の同じ分数を数直線に並べて大小を比べる
