Number Line Addition Worksheet: Count On and Write the Sum

Free math practice for home or the classroom. Print this Number Line Addition Worksheet: Count On and Write the Sum and its answer key on Letter paper, one page each.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Practice focus: number line addition worksheets 1 20. Focus: Counting On with a Number Line. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Count forward from any starting number.

Teaching Steps for Parents and Teachers

  1. Start at the first addend.
  2. Move forward the number of steps given by the second addend.
  3. The landing number is the sum.

Worked Examples

5 + 3 = □

  1. Start at 5.
  2. Count three steps: 6, 7, 8.

Answer: 8

Common Mistakes and How to Help

Do not count 5 as the first step.

How many forward steps did you take?

Questions to Check Understanding

  • How many forward steps did you take?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
