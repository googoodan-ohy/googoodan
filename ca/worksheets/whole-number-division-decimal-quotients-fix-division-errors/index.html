Teaching Notes

Focus: Whole Number ÷ Whole Number: Decimal Quotients. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read the numbers and identify the operation.

Teaching Steps for Parents and Teachers

  1. For an error-correction problem, find the first incorrect step. Explain why it is wrong, then recompute all later steps.
  2. If the divisor has decimal places, multiply both numbers by the same power of ten until the divisor is a whole number.
  3. The quotient stays the same.
  4. Divide using place value, keeping track of the decimal point in the quotient.
  5. These worksheets use the answers supplied by the existing calculation bank; do not round unless a question explicitly asks you to.

Worked Examples

Evaluate 3/4.

  1. Multiply both numbers by 1: 3 ÷ 4.
  2. Divide to get 0.75.
  3. Check: 0.75 × 4 = 3.

Answer: 0.75

Common Mistakes and How to Help

Moving only the divisor’s decimal point changes the problem. Apply the same shift to the dividend, and keep any zero needed to hold a quotient place.

Multiply the quotient by the original divisor. The result should return the original dividend.

Questions to Check Understanding

  • Multiply the quotient by the original divisor. The result should return the original dividend.
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.
