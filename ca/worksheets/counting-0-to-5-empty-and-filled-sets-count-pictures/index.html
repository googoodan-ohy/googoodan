Teaching Notes

Focus: Counting pictured sets, including an empty set represented by 0. Connect the number of objects to the numeral.

Before You Begin

  • Count forward and backward.

Teaching Steps for Parents and Teachers

  1. Count the objects shown in the picture.
  2. If the set is empty, no objects are present, so its count is zero.
  3. Check that the written numeral represents the pictured quantity.

Worked Examples

Count the apples in an empty basket: [empty]

  1. There are no apples to count.
  2. A set with no objects has a count of 0.

Answer: 0

Common Mistakes and How to Help

Writing 1 because the empty picture itself is one object.

Count the objects inside the picture. Are there any apples?

Questions to Check Understanding

  • How many objects are in the picture?
  • What numeral represents none?
  • What would change if one object were added?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
