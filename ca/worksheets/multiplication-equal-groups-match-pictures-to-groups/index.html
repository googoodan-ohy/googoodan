Teaching Notes

Focus: Equal Groups. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Count equal-sized groups.

Teaching Steps for Parents and Teachers

  1. Identify the number of groups and the number in each group.
  2. Add equal groups or multiply.
  3. Match each factor to the picture.
  4. For a matching problem, solve each item before drawing its connection. Check that the connected representations have equal values.

Worked Examples

There are 3 groups with 4 counters in each. How many counters?

  1. 4 + 4 + 4 = 12.
  2. 3 × 4 = 12.

Answer: 12

Common Mistakes and How to Help

Multiplication describes equal groups; check that each group has the same size.

Can you point to the groups and the objects in one group?

Questions to Check Understanding

  • Can you point to the groups and the objects in one group?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
