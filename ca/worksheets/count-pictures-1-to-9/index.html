Counting 1–9 Worksheet: Count Pictures and Write Numbers

Free math practice for home or the classroom. Print this Counting 1–9 Worksheet: Count Pictures and Write Numbers and its answer key on Letter paper, one page each.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Counting and Matching Numbers 1–9. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Say number names in order.

Teaching Steps for Parents and Teachers

  1. Point to one object as you say one number.
  2. Count each object once.
  3. The last number tells how many objects there are.

Worked Examples

Count these dots: ● ● ● ● ● ● ●

  1. Touch each dot once while saying 1, 2, 3, 4, 5, 6, 7.
  2. The last number is 7.

Answer: 7

Common Mistakes and How to Help

Counting an object twice changes the total.

Can you recount in a different direction and get the same total?

Questions to Check Understanding

  • Can you recount in a different direction and get the same total?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
