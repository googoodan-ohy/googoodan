Teaching Notes

Focus: Adding Hundredths: No Regrouping. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read the numbers and identify the operation.

Teaching Steps for Parents and Teachers

  1. For an error-correction problem, find the first incorrect step. Explain why it is wrong, then recompute all later steps.
  2. Line up decimal points so that ones, tenths, and hundredths match.
  3. Add trailing zeros if they help you see the places; this does not change a number.
  4. Add from the smallest place shown and regroup as needed.
  5. Put the decimal point in the sum directly below the other decimal points.

Worked Examples

Evaluate 2.34+1.25.

  1. Align the decimal points so corresponding places line up.
  2. Use trailing zeros if needed, then calculate one place at a time.
  3. 2.34 + 1.25 = 3.59

Answer: 3.59

Common Mistakes and How to Help

Align decimal points, not the right-hand ends of the numbers. For example, a tenth must not be added to a hundredth merely because both digits happen to be last.

Subtract either addend from the sum. Estimate with nearby whole numbers to check the size of the answer.

Questions to Check Understanding

  • Subtract either addend from the sum. Estimate with nearby whole numbers to check the size of the answer.
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.
