Fraction Measurement Line Plots: Read Halves and Quarters

Fraction Measurement Line Plots: Read Halves and Quarters: a printable math practice sheet with an answer key, ideal for printable math practice. Make fresh sets as often as you like and print on Letter paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read a number line and count marks.

Teaching Steps for Parents and Teachers

  1. Read the scale and units first.
  2. Each mark represents one observation unless a key says otherwise.
  3. Count marks to find frequency; use the horizontal position to find the measurement.

Worked Examples

A line plot has 3 marks over 2 and 2 marks over 3. How many observations are shown?

  1. There are 3 observations with value 2.
  2. There are 2 observations with value 3.
  3. 3 + 2 = 5.

Answer: 5

Common Mistakes and How to Help

The value on the axis and the number of marks are different quantities.

Did you count every observation exactly once?

Questions to Check Understanding

  • Did you count every observation exactly once?
  • What in the numbers or diagram supports your answer?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
