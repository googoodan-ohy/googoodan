Counting 1–9 Worksheet — Match Pictures and Numbers

Print a free Counting 1–9 Worksheet — Match Pictures and Numbers with a matching answer key on Letter paper, and make a new set of numbers whenever you need more practice.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Matching pictured quantities to numerals from 1 to 9. Model counting each group before drawing a match.

Before You Begin

  • Say number names in order.

Teaching Steps for Parents and Teachers

  1. Count each pictured group to find its number.
  2. Match each picture to the numeral with the same value.
  3. Check the match by recounting the picture.

Worked Examples

Match each picture to its number: ● ● ● → 2, 3, 4

  1. Count the three dots.
  2. Connect this picture to 3 because both represent three.

Answer: 3

Common Mistakes and How to Help

Matching a picture to a numeral without counting the objects.

Count the objects in this picture. Which numeral names that total?

Questions to Check Understanding

  • How many objects are in this group?
  • How can you check that the numeral and picture show the same amount?
  • What changes if one object is added?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
