Counting in Groups of 10 — Write the Number of Groups and the Total

Counting in Groups of 10 — Write the Number of Groups and the Total: a printable math practice sheet with an answer key, ideal for write the number of groups and the total math practice practice. Make fresh sets as often as you like and print on Letter paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Counting in Groups of 10. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read ones, tens, hundreds, and larger places.

Teaching Steps for Parents and Teachers

  1. Identify the place of each digit.
  2. Multiply the digit by its place value.
  3. Combine the values to recover the number.

Worked Examples

Write 40 in expanded form.

  1. Read each digit by its place value.
  2. Add the values of the nonzero digits.

Answer: 40

Common Mistakes and How to Help

A digit and its value are different: the 7 represents 70.

Do the place values add to the original number?

Questions to Check Understanding

  • Do the place values add to the original number?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
