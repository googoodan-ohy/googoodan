Grade 4: decimal models and place value

Grids and number lines connect tenths and hundredths to fractions and whole-number place value. Ask learners to read each decimal aloud, identify the value of every digit, and compare values by looking at the same place from left to right.

Grades 5–6: add and subtract decimals

Line up decimal points so digits with the same place value stay in one column. Students can add zeros as placeholders when needed. Estimating the sum or difference first makes it easier to catch a misplaced decimal point.

Grades 5–6: multiply and divide decimals

Use whole-number multiplication or division first, then reason about the decimal point from place value and the size of the answer. Include problems with a whole number and a decimal so students learn how the operand order affects division.
