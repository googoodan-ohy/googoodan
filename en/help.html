How to use Googoodan

Choose a skill, preview the answers, and print or save a PDF. No account is needed.

  1. Choose a learning menu.

    Basic arithmetic groups calculations by operation. Practice by level builds skills in a suggested sequence. US curriculum arithmetic groups calculation practice by grade and topic. US curriculum topics offers concept and application worksheets.

  2. Choose the worksheet and answer key.

    Use the preview buttons to check the answers. New numbers creates another set.

  3. Select copies.

    Each copy has different problems. Three copies with answers produces three worksheets and three answer keys.

  4. Print or save.

    Save PDF prepares an A4 file. Print opens your browser’s print dialog, where you can choose A4 or Letter. Use portrait orientation, 100% scale, and turn off headers and footers.

Using a phone

Look in your browser downloads or Files app for the PDF. Start with 1–3 copies on slower devices. If direct PDF preparation fails, choose Print and then Save as PDF where available.

Which curriculum is applied?

Current US practice uses selected Common Core standards. It is not a complete curriculum or an official state textbook. State-specific mappings and English, Canadian, and Australian curricula are planned. Selecting a country does not translate or align existing US questions automatically.

Found a mistake?

Choose Report an issue on the worksheet. Include the question number and describe the problem. The prepared message includes worksheet details; it is not sent automatically. Please remove student names from screenshots.
