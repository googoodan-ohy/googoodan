# Kindergarten worksheet collection

12 units, 54 authored profiles. Each page has three activities, two questions per activity. Numbers and pictures regenerate deterministically from the URL set parameter.

These are Common Core practice resources, not a complete assessment of all standards. Oral counting, physical measurement, and hands-on modeling also require adult-led activities. Open tasks have sample answers/check criteria. Ads are hidden during printing. Color-classification pages require color printing.

Validation: node en/check-kindergarten.cjs

Print fitting: start with 2 / 3 / 2 questions. Measure the answer layout at a 190 mm content width and a 250 mm sheet height. Remove the extra middle question first, then reduce other activities if needed, keeping at least one question per activity. The worksheet and answer key use the same fitting criteria. Browser headers and footers must be off; use portrait, 100% scale, and default CSS margins.
