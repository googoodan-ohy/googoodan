Teaching Notes

Practice focus: worksheets addition and subtraction with regrouping. Focus: Two Digits + Two Digits: Regroup Once. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read the numbers and identify the operation.

Teaching Steps for Parents and Teachers

  1. Read each number by place value.
  2. Add the ones, then the tens and any remaining places.
  3. When a column totals ten or more, exchange ten units for one unit in the next place.
  4. Record the carried amount before continuing.
  5. In a horizontal problem, you may rewrite the numbers vertically; the ones must still line up.
  6. Start in the ones place and subtract corresponding places.
  7. If a top digit is too small, exchange one unit from the next place for ten units in the current place.
  8. Mark both changes: the giving place decreases by one and the receiving place increases by ten.
  9. Continue left, using the changed digits.

Worked Examples

Evaluate 38+47.

  1. Place value 1: 8 + 7 = 15. Write 5 and carry 1 to the next place.
  2. Place value 10: 3 + 4 + 1 carried = 8. Write 8.

Answer: 85

Evaluate 62-28.

  1. Regroup from place value 10; it decreases by 1. There are now 12 units at place value 1.
  2. Place value 1: 12 − 8 = 4.
  3. Place value 10: 5 − 2 = 3.

Answer: 34

Common Mistakes and How to Help

A carried ten belongs in the next column. Do not write a two-digit total into a single place or forget to include a carry in the next sum.

Subtract one addend from the sum. The result should equal the other addend.

Do not reverse the digits just because the lower digit is larger. Subtraction keeps its original order. When a zero is involved, follow the exchange across the places rather than changing every zero independently.

Add the difference to the number subtracted. You should recover the starting number.

Questions to Check Understanding

  • Subtract one addend from the sum. The result should equal the other addend.
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.
