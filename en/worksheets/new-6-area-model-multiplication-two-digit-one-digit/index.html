Teaching Notes

Use the table to connect the two partial products to the original multiplication problem.

Before You Begin

  • Place value and two-digit by one-digit multiplication

Teaching Steps for Parents and Teachers

  1. Check that 20 and 3 at the top are the parts of 23.
  2. Where the row labeled 4 meets the column labeled 20, write 80.
  3. Where 4 and 3 meet, write 12.
  4. Add both cells to complete 23 × 4 = □ below the table.

Worked Examples

23 × 4 = 80 + 12 = 92

  1. Multiply 20 and 3 by 4 to get 80 and 12, then add. The table shows the calculation relationships; it is not drawn to scale.

Answer: 92

Common Mistakes and How to Help

Guessing from the size of the cells

The table is not drawn to scale. Multiply the row and column values to fill each cell.

Correcting the answer without explaining why

Check which multiplication each cell represents. Do not copy the row or column labels as answers. Have the student start again at the first incorrect step.

Questions to Check Understanding

  • Which multiplication gives 80 in the table?
  • What does each number in the worked example represent in the original problem?
  • Can you use the same method when the numbers change?

Practice Advice

Work through the example together and have the student explain why the answer is 92. Ask the student to explain the first two problems aloud, then solve the next three independently. Review the intermediate steps as well as the final answers. If an error repeats, return to the difficult teaching step before assigning more problems.

Next Practice

  • Choose New Numbers for more practice with the same conditions. Ask the student to explain the reasoning as well as give the answer.
  • If the student cannot explain the method independently, use smaller numbers to explore the same relationship first.
