Teaching Notes

Focus: Fractions with Denominator 100 as Decimals. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Recognize tenths and hundredths.

Teaching Steps for Parents and Teachers

  1. Read the denominator: 100 names hundredths.
  2. Write the numerator as a number of hundredths.
  3. Use two decimal places and check the fraction and decimal name the same amount.

Worked Examples

Write 37/100 as a decimal.

  1. The denominator 100 means hundredths.
  2. 37 hundredths is 3 tenths and 7 hundredths.

Answer: 0.37

Common Mistakes and How to Help

A denominator of 100 names hundredths, even when the numerator is one digit.

Write 7/100 as 0.07; zero holds the tenths place.

Questions to Check Understanding

  • How many hundredths does 37/100 name?
  • Why is 0.37 the same value as 37/100?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
