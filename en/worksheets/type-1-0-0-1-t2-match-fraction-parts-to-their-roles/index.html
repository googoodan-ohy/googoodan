Teaching Notes

Focus: Numerators and Denominators. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Identify a whole divided into equal parts.

Teaching Steps for Parents and Teachers

  1. Check that the parts are equal in size.
  2. Count all equal parts for the denominator.
  3. Count the selected parts for the numerator.
  4. For a matching problem, solve each item before drawing its connection. Check that the connected representations have equal values.

Worked Examples

A rectangle is divided into 4 equal parts. 3 are shaded. What fraction is shaded?

  1. There are 4 equal parts in the whole.
  2. 3 parts are selected.

Answer: 3/4

Common Mistakes and How to Help

Unequal pieces do not represent equal fractional parts.

Which number counts all equal parts, and which counts the selected parts?

Questions to Check Understanding

  • Which number counts all equal parts, and which counts the selected parts?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
