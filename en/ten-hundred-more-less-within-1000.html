Find 10 or 100 More or Less Within 1,000

Each set deliberately includes all four directions: 10 more, 10 less, 100 more, and 100 less. The values come from the existing second-grade mental-math generator.

This is a working worksheet generator, not a sample image. Choose New problems to make another set with the same learning goal. Switch between Worksheet and Answer key to preview both pages. The answer key always uses the same numbers as the current worksheet.

How students use this page

Use place value to find 10 more, 10 less, 100 more, or 100 less. Solve mentally, then check the answer key.

Ask which place changes before calculating. Students can explain that adding or subtracting 10 affects the tens place, while adding or subtracting 100 affects the hundreds place.

Keep the session short enough for the learner to work carefully. Review one error together and ask the student to explain the place-value or counting pattern used. A clear explanation shows whether the answer came from the intended idea rather than a guess. A later fresh set can check whether the same idea transfers to different numbers.

Grade-level focus

This practice is designed for Grade 2 and focuses on 2.NBT.B.8. It provides focused skill practice rather than a full assessment of the standard. Teachers can use one page for a warm-up, independent work, a math center, tutoring, or a short home review.
