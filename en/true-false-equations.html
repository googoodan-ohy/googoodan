True or False Math Equations Worksheets: hands-on printable practice

Free printable true or false equation worksheets for first grade. Check both sides of the equal sign, find errors, and write corrected equations.

Grade 1 · understand the equal sign. This printable activity gives children something concrete to count, color, draw, cross out, match, or explain. It provides focused practice for 1.OA.D.7 and a matching answer key for the exact generated set.

What children practice

These activities make the equal sign mean “the same value as.” Children decide whether a statement is true and correct a nearby error rather than calculating isolated facts only.

  • Decide true or false
  • Find and fix an error

How to use the activity

Calculate the left side before looking at the proposed answer. If the values differ, write a corrected equation and explain whether the original answer was one too high or one too low.

Read the first direction together and let the child complete the physical action before writing a number. Ask, “How do you know?” after one item. That short explanation reveals whether the picture, model, and equation make sense together. Use crayons, a pencil, small counters, or a straightedge when the activity calls for them.

Select New problems to make a fresh set with new numbers or pictures. Switch between Worksheet and Answer key to preview both pages. The selected worksheet and answer key use the same set, so every answer stays aligned. Choose either page or both in the print controls, then print on US Letter or A4 paper. A browser print dialog can also save the activity as a PDF.

The worksheet is free for home practice, tutoring, and classroom use. Begin with a level the learner can complete accurately, then generate a new set for another short session. Hands-on work should support mathematical thinking, so accuracy and a clear explanation matter more than speed.
