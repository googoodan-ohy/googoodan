Practice addition with exact regrouping

Three-Digit Addition with One Regrouping Worksheets gives Grade 3 students a precise place-value practice set. Every calculation is generated by the same tested arithmetic bank used by the Korean worksheet collection, then presented with English directions and an American grade-level reference.

What students practice

Students add from right to left and record a new ten or hundred only when a place-value sum reaches 10. This focused set is filtered by the established source generator so each calculation has exactly 1 regrouping step. Students work across the ones, tens, and hundreds places, show their steps, find missing values by using inverse operations, and decide whether a sample calculation is correct.

This page provides focused Grade 3 fluency practice with three-digit addition or subtraction. It is aligned as targeted practice for Common Core 3.NBT.A.2 rather than a complete assessment of every part of that standard.

How to use the worksheet

Begin with the first two calculations and ask the student to mark each place where a value is regrouped. The next two questions hide a number, so the learner must use the relationship between operations. The final two questions ask the learner to check and correct another calculation. This sequence moves from performing a method to explaining and checking it.

Choose New problems for a fresh set with the same exact regrouping condition. Use Worksheet and Answer key to preview the matching pages. You can print either page or both, and the browser can save the same pages as a PDF. No sign-up is required.

Teaching tip

Ask the learner to say which place is being regrouped and why. A spoken explanation such as “I exchanged one hundred for ten tens” is more useful than memorizing a mark above a digit. If an answer is incorrect, compare it with the matching answer key, correct one place at a time, and then generate another short set.
