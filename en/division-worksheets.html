Grade 3: connect multiplication and division facts

Division facts make more sense when students can name the related multiplication equation. Use equal groups, arrays, and missing-factor practice to show how a total is split into equal parts. Fact work should include both the size of each group and the number of groups.

Divide fractions and decimals

Fraction division asks how many groups of one size fit in another amount. Decimal division uses the same whole-number reasoning with close attention to place value. Estimate the quotient first so a misplaced decimal point is easier to notice.
