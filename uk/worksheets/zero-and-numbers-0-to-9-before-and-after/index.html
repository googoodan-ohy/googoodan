Teaching Notes

Focus: Finding the number immediately before and after a given number from 0 to 9.

Before You Begin

  • Count forward and backward.

Teaching Steps for Parents and Teachers

  1. Read the given number.
  2. Find the number immediately before it and the number immediately after it.
  3. Check by counting forward and backward one step.

Worked Examples

Write the number before and the number after 5: □, 5, □

  1. Count back one from 5 to get 4.
  2. Count forward one from 5 to get 6.

Answer: 4 and 6

Common Mistakes and How to Help

Writing 5 itself in one of the neighboring positions.

Move one count backward for the first blank and one count forward for the second.

Questions to Check Understanding

  • What comes just before 5?
  • What comes just after 5?
  • How can you check each neighbor?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
