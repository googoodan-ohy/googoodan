Teaching Notes

Focus: Finding the Number of Equal Groups. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Understand equal groups.

Teaching Steps for Parents and Teachers

  1. Identify the total number of objects.
  2. Identify the number in each group.
  3. Make equal groups and count the groups.
  4. Multiply the number of groups by the group size to check the total.

Worked Examples

Put 12 counters into groups of 3. How many groups can you make?

  1. Make groups with 3 counters in each.
  2. Four groups use all 12 counters.
  3. 12 ÷ 3 = 4 and 4 × 3 = 12.

Answer: 4 groups

Common Mistakes and How to Help

The answer counts groups, not counters in each group.

Here the group size is already given as 3; the unknown is the number of groups.

Questions to Check Understanding

  • What is known: the number of groups or the number in each group?
  • Do four groups of three counters use all 12 counters?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
