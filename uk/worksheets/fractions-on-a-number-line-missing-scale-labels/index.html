Teaching Notes

Focus: Fractions on a Number Line. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Recognize one whole on a number line.

Teaching Steps for Parents and Teachers

  1. Find the interval from 0 to 1.
  2. Divide it into equal intervals using the denominator.
  3. Count intervals from 0 to locate the numerator.
  4. For a blank, identify the missing quantity. Substitute the completed value back into the original statement to check it.

Worked Examples

A number line from 0 to 1 has 4 equal intervals. What is the third mark after 0?

  1. Each interval is 1/4.
  2. Three intervals give 3 × 1/4 = 3/4.

Answer: 3/4

Common Mistakes and How to Help

Count intervals rather than including the mark at 0.

Is 3/4 between 0 and 1?

Questions to Check Understanding

  • Is 3/4 between 0 and 1?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
