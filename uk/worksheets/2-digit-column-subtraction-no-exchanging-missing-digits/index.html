2-Digit Column Subtraction, No Exchanging: Missing Digits Worksheet

Free maths practice for home or the classroom. Print this 2-Digit Column Subtraction, No Exchanging: Missing Digits Worksheet and its answer key on A4 paper, one page each.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Two Digits − Two Digits: No Regrouping. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read the numbers and identify the operation.

Teaching Steps for Parents and Teachers

  1. Align corresponding place values.
  2. Work from the smallest place to the greatest place.
  3. This worksheet uses calculations without regrouping. Record each place value carefully.
  4. Check the result using the inverse operation.
  5. For a blank, identify the missing quantity. Substitute the completed value back into the original statement to check it.

Worked Examples

Evaluate 68-25.

  1. Place value 1: 8 − 5 = 3.
  2. Place value 10: 6 − 2 = 4.

Answer: 43

Common Mistakes and How to Help

Digits in different places have been combined.

Point to each place value before calculating, and keep the digits aligned.

Questions to Check Understanding

  • Add the difference to the number subtracted. You should recover the starting number.
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
