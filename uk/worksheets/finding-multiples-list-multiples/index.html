Teaching Notes

Focus: Finding Multiples. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Use repeated addition.

Teaching Steps for Parents and Teachers

  1. Multiply the number by 1, 2, 3, and so on.
  2. Alternatively, repeatedly add the number.
  3. Stop when the question’s requested count or limit is reached.

Worked Examples

List the first four positive multiples of 3.

  1. 3 × 1 = 3; 3 × 2 = 6.
  2. 3 × 3 = 9; 3 × 4 = 12.

Answer: 3, 6, 9, 12

Common Mistakes and How to Help

Do not confuse multiples with factors.

Is each successive number 3 greater than the previous one?

Questions to Check Understanding

  • Is each successive number 3 greater than the previous one?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
