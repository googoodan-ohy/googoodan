Teaching Notes

Focus: Using the Least Common Denominator. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Find multiples and equivalent fractions.

Teaching Steps for Parents and Teachers

  1. For an error-correction problem, find the first incorrect step. Explain why it is wrong, then recompute all later steps.
  2. Find a common multiple of the denominators.
  3. Rewrite each fraction with that denominator.
  4. Multiply each numerator by the same factor used for its denominator.

Worked Examples

Write 1/2 and 2/3 with denominator 6.

  1. For 1/2, multiply numerator and denominator by 3.
  2. For 2/3, multiply both by 2.

Answer: 3/6 and 4/6

Common Mistakes and How to Help

Do not change a denominator without changing its numerator proportionally.

Do the rewritten fractions have the original values?

Questions to Check Understanding

  • Do the rewritten fractions have the original values?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
