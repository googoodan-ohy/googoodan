Comparing Capacity Using Equal-Sized Cups Worksheet

Comparing Capacity Using Equal-Sized Cups Worksheet: a printable maths practice sheet with an answer key, ideal for comparing capacity using equal sized cups practice. Make fresh sets as often as you like and print on A4 paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Distinguish capacity from the amount currently in a container.

Teaching Steps for Parents and Teachers

  1. Compare how much each container can hold.
  2. Use equal-sized units or a direct transfer when appropriate.
  3. Choose the greater or smaller capacity as requested.

Worked Examples

Container A holds 3 equal cups. Container B holds 5 of the same cups. Which holds more?

  1. Both capacities use the same cup.
  2. 5 > 3.

Answer: Container B

Common Mistakes and How to Help

The height of a container alone does not determine its capacity.

Were the measuring cups the same size?

Questions to Check Understanding

  • Were the measuring cups the same size?
  • What in the numbers or diagram supports your answer?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice
