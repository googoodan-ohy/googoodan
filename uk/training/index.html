Choosing a useful maths practice sheet

Use the fixed learning buttons to open a practice area, then choose Whole Numbers, Fractions or Decimals and the next step, such as Getting Ready or an operation. This order helps you keep one idea in focus: a pupil who is still building number bonds can practise those before moving to addition across a ten or a written calculation. The worksheet cards show a real preview. Open the magnifier when you want to inspect the question layout, then select the card to open its full worksheet.

On the detail page, switch between Questions and Answers to review the work, use New Numbers for another set of the same type, and press Print when the sheet is ready. The question page and answer page are selected separately, so check which one is visible before printing. For a short session, solve one example together, ask the pupil to explain the tens and ones, then let them try a few independently. A misplaced digit, a forgotten exchange and a rushed subtraction call for different follow-up practice.

For multiplication, connect a fact to equal groups, arrays, or a known times-table pattern. For division, talk about how many groups can be made and what a remainder means in context. When comparing fractions, make sure the wholes are equal before comparing the parts. With decimals, line up the decimal points and name the place value of each digit. These prompts help distinguish a calculation slip from a gap in the underlying idea.

Choose a shorter page when attention is limited, and leave space between practice sessions. If errors cluster around one step, return to that step rather than assigning a larger set. The worksheet list is organised by number type and learning step, so a parent or teacher can move from a familiar representation to a new one without losing sight of the current skill. The pages are set up for A4 paper; check the print preview before printing so the worksheet remains on one sheet.
