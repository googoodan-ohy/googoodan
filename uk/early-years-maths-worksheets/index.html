Choosing early-years number practice

These pages support early number work through counting, numeral recognition, comparing groups and building simple number facts. Choose a sheet by the action a child is ready to practise. If counting objects is still developing, use a small range and point to each item once. When numerals are recognised reliably, match a written number to a group or complete a short number sequence. Number bonds can follow once the child can explain that two parts make the same whole. Keep the first choice visually simple so the mathematical idea stands out.

Choose a small, clear task

Before printing, look at the number range and the amount of writing required. A young learner may be ready to count aloud but not yet write every answer independently; an adult can record the first few responses while the child points. Open a worksheet, choose Worksheet for an attempt, and use Answer Key only after the child has had time to think. Fresh numbers make a familiar task usable again, but keep the same skill for a few examples before changing the format.

Use objects to show a number bond

Try a small example with seven counters. Put three on one side and four on the other, count each group, then join them and count all seven. Ask what could change if one counter moved: the groups would become four and three, while the total would stay seven. This links counting, comparison and the number bond 3 + 4 = 7 without introducing a new rule. For a sequence, say 5, 6, __, 8 and invite the child to continue counting from the known number.

Common slips to catch

Watch for skipping an object, counting the same object twice, or saying the next number without matching it to the next item. Move counters one at a time into a new row to make progress visible. When matching numerals, check that the written symbol and the counted group refer to the same amount. Avoid rushing from a successful answer to a larger range; repeat the idea with a different small group first. If attention fades, stop after a few careful responses and return later.
