집계 기준

한국 시간 기준입니다. 하루에 같은 브라우저로 여러 번 방문해도 방문자 1명으로 계산합니다. 누적 방문자는 일별 방문자 수의 합계입니다. 전체 방문자는 한국·미국을 오간 같은 브라우저의 중복을 제거합니다.

기기나 브라우저가 다르면 별도로 집계될 수 있습니다. 인쇄·PDF 수치는 버튼 클릭 횟수이며 실제 출력·저장 완료 횟수가 아닙니다. 공용 버튼은 별도 항목으로 표시합니다.

집계 연결 이후의 기록만 표시하며, 이전 방문 기록을 소급해 만들지 않습니다.
