How to use the printable maths collection

This landing page is a route into the separate worksheet collections, from number facts to fractions, shape and measurement. Choose a topic that reflects the next skill to practise, then use its page to narrow the choice to a format or question type. Starting with one clear goal keeps a printable session manageable. A learner working on column addition, for example, can open the addition and subtraction collection and select a column layout instead of browsing every available sheet.

Set up a short session

Open a worksheet and read its title before printing. Choose Worksheet for questions, Answer Key for checking, or both when an adult will review the work. New Numbers makes a fresh set, so the same skill can be practised again without repeating identical questions. The sheets are arranged for A4 paper; use the browser print dialog or Save as PDF. Check the preview before printing, especially if the browser has added headers, footers or a different paper size.

A useful pattern is to attempt a small group of questions, pause to check one method, then finish the set. For example, when practising multiplication, solve 6 × 7 as six groups of seven or as 5 × 7 plus 7. Then use the answer page to confirm 42. Explaining how an answer was found gives more information than marking it right or wrong alone. If the same step is unclear, return to a simpler page in that topic before selecting a harder format.

Use the answer page well

Compare each answer with the key only after an attempt. When one answer differs, rework that line and find the first step that changed. Check signs, place value, copied numbers and units before assuming a calculation error. For a question with several steps, keep the working visible so the source of a mismatch can be found. Avoid changing several things at once; a fresh worksheet with the same format is a good next check.

Move between topics when the learner is ready, not simply because one page is finished. A session may use number facts as a warm-up or stay with one skill. The topic links return you to a collection, whose titles guide you to a sheet.
