Teaching Notes

Practice focus: using a number line worksheet. Focus: Locating Numbers on a Number Line. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Count equal intervals.

Teaching Steps for Parents and Teachers

  1. Read two labeled points to find the value of one interval.
  2. Count intervals from a known point.
  3. Write the value at the requested point.

Worked Examples

The marks on a line are 0, 2, □, 6. Find the missing value.

  1. There are equal steps of 2.
  2. 2 + 2 = 4.

Answer: 4

Common Mistakes and How to Help

Count spaces between marks, not the marks themselves.

Does the same step size work between every pair of adjacent marks?

Questions to Check Understanding

  • Does the same step size work between every pair of adjacent marks?
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
