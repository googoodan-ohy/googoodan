Zero and Numbers 0–9: Line Blanks Worksheet

Zero and Numbers 0–9: Line Blanks Worksheet: a printable maths practice sheet with an answer key, ideal for zero and numbers 0–9 practice. Make fresh sets as often as you like and print on A4 paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Reading a number line and writing a missing number from 0 to 9. Use the labeled ticks and counting interval.

Before You Begin

  • Count forward and backward.

Teaching Steps for Parents and Teachers

  1. Read the labeled numbers on the number line.
  2. Determine the counting interval between tick marks.
  3. Use that interval to identify and write the number at the blank tick.

Worked Examples

Fill the missing number on the number line: 0 — 1 — □ — 3

  1. Each tick increases by 1.
  2. The tick after 1 and before 3 is 2.

Answer: 2

Common Mistakes and How to Help

Counting tick marks instead of the spaces between them.

Start at the labeled tick 0 and move one space at a time. What number is at the blank tick?

Questions to Check Understanding

  • What value does each tick mark represent?
  • How many spaces from 0 to the blank?
  • Does the answer fit between the neighboring labels?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
