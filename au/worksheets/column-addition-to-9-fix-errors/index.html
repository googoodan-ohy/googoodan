Column Addition to 9: Fix Errors Worksheet: a printable maths practice sheet with an answer key, ideal for addition to 9 practice. Make fresh sets as often as you like and print on A4 paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Addition with Sums up to 9. Use the worked example and teaching sequence below to explain the reasoning before independent practice.

Before You Begin

  • Read the numbers and identify the operation.

Teaching Steps for Parents and Teachers

  1. For an error-correction problem, find the first incorrect step. Explain why it is wrong, then recompute all later steps.
  2. Read each number by place value.
  3. Add the ones, then the tens and any remaining places.
  4. When a column totals ten or more, exchange ten units for one unit in the next place.
  5. Record the carried amount before continuing.
  6. In a horizontal problem, you may rewrite the numbers vertically; the ones must still line up.

Worked Examples

Evaluate 3+5.

  1. Place value 1: 3 + 5 = 8. Write 8.

Answer: 8

Common Mistakes and How to Help

A carried ten belongs in the next column. Do not write a two-digit total into a single place or forget to include a carry in the next sum.

Subtract one addend from the sum. The result should equal the other addend.

Questions to Check Understanding

  • Subtract one addend from the sum. The result should equal the other addend.
  • Which step explains your answer?
  • Can you apply the same reasoning when the numbers change?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • If the learner needs help, return to the example and model each step before trying again.
