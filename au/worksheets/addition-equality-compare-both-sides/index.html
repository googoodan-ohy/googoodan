Addition Equality Worksheet: Compare Both Sides

Free maths practice for home or the classroom. Print this Addition Equality Worksheet: Compare Both Sides and its answer key on A4 paper, one page each.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Students check whether both sides of the equal sign have the same value.

Before You Begin

  • Single-digit addition and the meaning of the equals sign

Teaching Steps for Parents and Teachers

  1. Calculate 5 + 2 on the left side to get 7.
  2. Calculate 4 + 3 on the right side to get 7.
  3. Both sides have the same value, so the equation is true.
  4. Change one number on the right. Check that the equation is false when the values differ.

Worked Examples

5 + 2 = 4 + 3

  1. Both sides equal 7, so the equation is true.

Answer: True: both sides equal 7.

Common Mistakes and How to Help

Calling an equation false because the numbers look different

Have the student compare the values of the expressions, rather than how they look.

Correcting the answer without explaining why

Check both sides to show that the equal sign expresses a relationship. It does not simply mean to write an answer. Have the student start again at the first incorrect step.

Questions to Check Understanding

  • Can the two sides have the same value even if their numbers differ?
  • What does each number in the worked example represent in the original problem?
  • Can you use the same method when the numbers change?

Practice Advice

Work through the example together. Have the student explain why it is true: both sides equal 7. Ask the student to explain the first two problems aloud, then solve the next three independently. Review both calculations and the true-or-false decision. If an error repeats, return to the difficult teaching step before assigning more problems.

  • If the student cannot explain the method independently, use smaller numbers to explore the same relationship first.
