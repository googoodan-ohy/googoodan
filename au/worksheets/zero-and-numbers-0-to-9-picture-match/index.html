Zero and Numbers 0–9: Picture Match Worksheet

Zero and Numbers 0–9: Picture Match Worksheet: a printable maths practice sheet with an answer key, ideal for zero and numbers 0–9 practice. Make fresh sets as often as you like and print on A4 paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Matching pictures that show 0 to 9 objects with numerals. Count each set before connecting it.

Before You Begin

  • Count forward and backward.

Teaching Steps for Parents and Teachers

  1. Count the objects in each picture, including an empty picture as zero.
  2. Match each picture to the numeral with the same value.
  3. Recount one matched picture to verify the connection.

Worked Examples

Match the picture to its number: ● ● ● → 2, 3, 4

  1. The picture has three dots.
  2. Connect it to 3, which names the same quantity.

Answer: 3

Common Mistakes and How to Help

Matching by the appearance or position of a numeral instead of its value.

Count the objects in the picture. Which numeral represents that count?

Questions to Check Understanding

  • How many objects are shown?
  • Which numeral has the same value?
  • How would an empty picture be matched?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
