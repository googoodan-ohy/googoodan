Counting 1–9: Draw Quantities Worksheet

Counting 1–9: Draw Quantities Worksheet: a printable maths practice sheet with an answer key, ideal for counting 1–9 practice. Make fresh sets as often as you like and print on A4 paper.

Use New Numbers to make another set. Choose Worksheet or Answer Key, then use the worksheet’s Print button.

Teaching Notes

Focus: Showing a given number by coloring or marking that many objects. Have the learner read the numeral, make the set, and recount it.

Before You Begin

  • Say number names in order.

Teaching Steps for Parents and Teachers

  1. Read the numeral first.
  2. Color or mark exactly that many objects.
  3. Count the marked objects to check the quantity.

Worked Examples

Color 5 circles: ○ ○ ○ ○ ○ ○

  1. Count five circles from left to right and color them.
  2. Leave the sixth circle uncolored.

Answer: 5 circles colored

Common Mistakes and How to Help

Coloring one too many or one too few objects.

Count only the colored circles. Do you have exactly five?

Questions to Check Understanding

  • What number are you showing?
  • How many circles should be colored?
  • How can you check the count?

Practice Advice

Work through the example together. Ask the learner to explain the first two problems, then try three independently. Review the first incorrect step before assigning more practice.

Next Practice

  • Use New Numbers to practice the same skill with different values.
  • If the learner needs help, return to the example and model each step before trying again.
