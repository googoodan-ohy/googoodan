곱셈구구 표 채우기

자연수 · 곱셈 · 6단·7단

같은 수의 묶음을 곱셈구구로 빠르게 구하고 곱셈식의 세 수 사이 관계를 익힙니다.

먼저 확인할 내용

  • 같은 수의 반복 덧셈
  • 묶음 수와 한 묶음의 크기 구별

학부모·선생님의 지도 순서

  1. 행과 열의 제목을 먼저 읽고 칸이 어떤 관계를 나타내는지 정합니다. 각 칸을 채운 뒤 이웃 칸과 증가량 또는 공통 관계를 확인합니다.
  2. 한 묶음의 개수와 묶음 수를 식의 두 수에 대응시킵니다.
  3. 이미 아는 구구의 곱에 한 묶음을 더하거나 빼서 모르는 곱을 찾습니다.
  4. 곱을 같은 수의 반복 덧셈이나 나눗셈으로 확인합니다.

대표 문제와 풀이

곱셈표의 행이 6, 열이 8인 칸을 채우세요.

  1. 행의 수 6와 열의 수 8를 곱합니다.
  2. 교차하는 칸에 곱 48의 값을 씁니다.
예제 정답 보기48

자주 하는 실수와 지도 방법

곱셈구구의 앞뒤 식을 섞어 곱을 답합니다.

6×8가 헷갈리면 6×7=42에 한 묶음 6를 더해 48를 확인합니다. 외운 구구와 실제 묶음이 같은지 확인하세요.

옆 칸 답을 그대로 따라 씁니다.

행·열의 기준이 바뀌면 계산도 달라지는 이유를 말하게 하세요.

아이의 이해를 확인하는 질문

  • 6개씩 8묶음이면 같은 수를 몇 번 더할까?
  • 6×7의 곱에 한 묶음 6를 더하면 무엇이 될까?
  • 식을 거꾸로 읽어 나눗셈으로 확인하면 어떤 식이 될까?

문제지 활용과 채점 후 지도

이 유형의 예제 답은 48입니다. 손가락으로 묶음 수를 세거나 점 배열을 그려 구구의 곱과 맞는지 확인하게 합니다. 표의 행과 열을 먼저 읽는지 관찰합니다.

다음 연습

  • 같은 단의 이웃 구구를 골라 곱이 한 묶음 크기만큼 변하는지 확인합니다.
  • 곱을 말한 뒤 해당 곱셈식과 짝인 나눗셈식을 하나 만들어 봅니다.
