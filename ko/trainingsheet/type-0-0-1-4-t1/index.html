그림 두 묶음을 합쳐 수 쓰기

자연수 · 선행 학습 · 10 만들기

전체를 두 부분으로 나누거나 두 부분을 합쳐 전체를 만드는 관계를 익힙니다.

먼저 확인할 내용

  • 전체 개수 세기

학부모·선생님의 지도 순서

  1. 그림의 전체, 묶음, 낱개를 손으로 짚습니다. 직접 표시한 결과를 수나 식으로 옮겨 그림과 답을 서로 대조합니다.
  2. 전체 수와 이미 주어진 부분 수를 구별합니다.
  3. 물건을 실제로 나누거나 합쳐 나머지 부분을 찾습니다.
  4. 두 부분을 다시 합쳐 전체와 같은지 확인합니다.

대표 문제와 풀이

4개와 6개를 합하면 모두 몇 개인가요? 먼저 물건이나 묶음을 그려 숫자가 나타내는 부분을 표시하세요.

  1. 문제에 나오는 수를 물건의 개수, 묶음 크기, 묶음 수 또는 전체 수로 구별해 표시합니다.
  2. 첫 묶음은 4개, 둘째 묶음은 6개입니다.
  3. 4+6=10이므로 모두 10개입니다.

자주 하는 실수와 지도 방법

부분 수를 전체 수로 착각합니다.

관계도의 위쪽 전체와 아래쪽 두 부분을 실제 물건으로 대응시키세요.

그림을 세지 않고 숫자만 보고 답합니다.

숫자가 그림의 어느 부분에서 나온 값인지 짚게 하세요.

아이의 이해를 확인하는 질문

  • 두 부분을 합치면 원래 몇 개가 되어야 할까?
  • 예제에서 4+6의 값이 10인 이유를 물건이나 계산으로 보여 줄래?
  • 이 수를 물건이나 자리별 묶음으로 나타내면 어떻게 될까?

문제지 활용과 채점 후 지도

대표 예제의 답 10를 아이가 설명할 수 있는지 먼저 봅니다. 관찰할 점은 두 부분을 합해 처음 전체를 만드는지입니다. 처음 두 문제는 풀이를 말하게 하고 이후 세 문제는 혼자 풀게 합니다. 같은 실수가 반복되면 계산량을 늘리지 말고 문제 표현을 그림이나 물건으로 바꿉니다.

다음 연습

  • 두 부분을 합해 처음 전체를 만드는지를 확인한 뒤 같은 조건의 다른 수로 다시 설명하게 합니다.
  • 독립적으로 설명하기 어렵다면 대표 예제의 수를 더 작은 수로 바꾸어 물건으로 확인합니다.
