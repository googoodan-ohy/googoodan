0~9 수 배열의 빈칸 채우기

자연수 · 선행 학습 · 0의 뜻과 0~9의 수 순서

물건 하나와 수 이름 하나를 대응시키며 마지막에 말한 수가 전체 개수임을 익힙니다.

먼저 확인할 내용

  • 물건을 하나씩 짚기

학부모·선생님의 지도 순서

  1. 등호 양쪽에서 같은 값이 되도록 빈칸의 역할을 읽습니다. 한 칸씩 채운 뒤 식 또는 배열 전체가 맞는지 확인합니다.
  2. 그림을 일정한 방향으로 하나씩 짚습니다.
  3. 이미 센 그림은 다시 세지 않도록 표시합니다.
  4. 마지막 수를 전체 개수로 쓰고 숫자로도 읽어 봅니다.

대표 문제와 풀이

0, 1, 2, 빈칸, 4의 빠진 수를 쓰세요.

  1. 0부터 한 칸마다 1씩 증가합니다.
  2. 2 다음의 수는 2+1=3입니다.

자주 하는 실수와 지도 방법

그림 하나를 두 번 세거나 숫자 이름만 외웁니다.

손으로 짚는 속도와 말하는 속도를 맞춰 주세요. 빈 그림은 0이라고 말합니다.

빈칸 앞 숫자와 뒤 숫자를 무조건 더합니다.

빈칸이 무엇을 뜻하는지 먼저 말하고 계산을 고르게 하세요.

아이의 이해를 확인하는 질문

  • 다 세고 마지막에 말한 수가 무엇이니?
  • 예제에서 2+1의 값이 3인 이유를 물건이나 계산으로 보여 줄래?
  • 빈칸 값을 넣으면 앞부분과 뒷부분이 모두 맞아질까?

문제지 활용과 채점 후 지도

대표 예제의 답 3를 아이가 설명할 수 있는지 먼저 봅니다. 관찰할 점은 하나의 그림을 한 번씩만 세었는지입니다. 빈칸 하나를 채운 뒤 그 앞뒤 식이나 배열을 다시 읽게 합니다. 답만 맞힌 경우에도 어떤 수가 빠졌는지 이유를 확인합니다.

다음 연습

  • 하나의 그림을 한 번씩만 세었는지를 확인한 뒤 같은 조건의 다른 수로 다시 설명하게 합니다.
  • 독립적으로 설명하기 어렵다면 대표 예제의 수를 더 작은 수로 바꾸어 물건으로 확인합니다.
