주어진 수의 위치 표시하기

자연수 · 선행 학습 · 수직선에서 수의 위치 찾기

같은 간격의 눈금은 같은 수 차이를 나타냅니다. 시작 수와 한 칸의 크기를 확인해 위치를 찾습니다.

먼저 확인할 내용

  • 수의 순서
  • 한 칸씩 세기

학부모·선생님의 지도 순서

  1. 제시한 수를 먼저 읽습니다.
  2. 점이나 표시를 하나 만들 때마다 하나씩 세어 제시 수만큼 만듭니다.
  3. 완성한 표시를 다시 세어 제시 수와 같은지 확인합니다.

대표 문제와 풀이

0에서 한 칸에 1씩, 오른쪽으로 6칸 간 위치의 수는? 먼저 물건이나 묶음을 그려 숫자가 나타내는 부분을 표시하세요.

  1. 문제에 나오는 수를 물건의 개수, 묶음 크기, 묶음 수 또는 전체 수로 구별해 표시합니다.
  2. 0에서 오른쪽으로 1칸씩 이동합니다.
  3. 6칸 뒤의 수는 0+6=6입니다.

자주 하는 실수와 지도 방법

출발 눈금을 첫 번째 칸으로 셉니다.

눈금 사이의 공간을 손가락으로 넘기며 칸을 세게 하세요.

수를 읽고도 그보다 많거나 적게 표시합니다.

표시 하나에 수 이름 하나를 대응하고 제시한 수에서 멈추게 하세요.

아이의 이해를 확인하는 질문

  • 눈금 사이 한 칸이 나타내는 수는 얼마일까?
  • 예제에서 0+6의 값이 6인 이유를 물건이나 계산으로 보여 줄래?
  • 너의 표시를 다시 읽으면 제시된 수나 순서와 같니?

문제지 활용과 채점 후 지도

대표 예제의 답 6를 아이가 설명할 수 있는지 먼저 봅니다. 관찰할 점은 하나의 그림을 한 번씩만 세었는지입니다. 표시를 완성한 뒤 시작점과 끝점 또는 표시 개수를 다시 확인하게 합니다. 제시된 수에서 멈출 수 있는지 봅니다.

다음 연습

  • 하나의 그림을 한 번씩만 세었는지를 확인한 뒤 같은 조건의 다른 수로 다시 설명하게 합니다.
  • 독립적으로 설명하기 어렵다면 대표 예제의 수를 더 작은 수로 바꾸어 물건으로 확인합니다.
