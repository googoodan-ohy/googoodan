수를 보고 그만큼 표시하기

자연수 · 선행 학습 · 1~9의 수 세기와 숫자 연결

제시한 숫자를 읽고 그 수만큼 표시를 직접 만듭니다. 그림을 세어 숫자를 쓰는 활동과 반대로, 숫자를 출발점으로 삼아 정확한 개수의 그림을 구성합니다.

먼저 확인할 내용

  • 물건을 하나씩 짚기

학부모·선생님의 지도 순서

  1. 제시한 수를 먼저 읽습니다.
  2. 점이나 표시를 하나 만들 때마다 하나씩 세어 제시 수만큼 만듭니다.
  3. 완성한 표시를 다시 세어 제시 수와 같은지 확인합니다.

대표 문제와 풀이

수 7을 보고 그만큼 점을 그리세요.

  1. 점 하나를 그릴 때마다 1부터 차례로 셉니다.
  2. 7에서 멈춥니다. 완성한 점을 다시 세어 7개인지 확인합니다.
예제 정답 보기점 7개

자주 하는 실수와 지도 방법

수를 읽은 뒤 표시를 하나 더 그리거나 목표 수에 도달하기 전에 멈춥니다.

표시 하나를 그릴 때 수 이름도 하나만 말합니다. 제시한 수를 말하는 순간 새 표시를 더 그리지 않게 합니다.

만든 표시를 다시 세지 않아 목표 수와 다른 개수를 남깁니다.

완성 후 각 표시를 한 번씩 짚어 다시 세고 숫자와 같을 때만 마치게 하세요.

아이의 이해를 확인하는 질문

  • 어떤 숫자를 읽고 표시를 만들었니?
  • 7개를 만들려면 몇 번째 표시에서 멈춰야 할까?
  • 완성한 표시를 다시 세면 제시한 수와 같니?

문제지 활용과 채점 후 지도

숫자 7을 보여 주고 아이가 스스로 7개의 점을 만든 뒤 다시 세게 하세요. 적거나 많으면 표시를 처음부터 지우지 말고 몇 개를 더하거나 지워야 맞는지 찾아보게 합니다.

다음 연습

  • 하나의 그림을 한 번씩만 세었는지를 확인한 뒤 같은 조건의 다른 수로 다시 설명하게 합니다.
  • 독립적으로 설명하기 어렵다면 대표 예제의 수를 더 작은 수로 바꾸어 물건으로 확인합니다.
