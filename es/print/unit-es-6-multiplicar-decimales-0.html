Guía de aprendizaje

Multiplicar números decimales con precisión

Multiplicar decimales como números enteros y colocar después la coma según las cifras decimales de los factores.

Los ejercicios combinan un número natural con uno decimal y productos de dos decimales. También hay factores desconocidos en productos dados y una sección final para validar resultados. Para multiplicar, se puede ignorar inicialmente la coma, calcular el producto entero y contar las cifras decimales que tenían ambos factores. La coma del resultado se coloca con esa cantidad de cifras. Al estimar el tamaño del producto se detectan desplazamientos incorrectos.

Antes de empezar

  • Conocer las tablas de multiplicar y el algoritmo de productos naturales.
  • Leer y descomponer números decimales con coma.

Cómo resolverlo

  1. Multiplica las cifras como si los factores fueran números enteros.
  2. Cuenta las cifras decimales totales de los factores.
  3. Coloca la coma en el producto para dejar el mismo número de cifras decimales.
  4. Si falta un factor, divide el producto conocido entre el otro factor y verifica multiplicando.

Ejemplo resuelto

Calcula 4,6 × 3,2.

  1. Ignora las comas: 46 × 32 = 1472.
  2. Hay dos cifras decimales en total, así que el resultado es 14,72.
Ver la respuesta

14,72

Completa 2,5 × □ = 8,75.

  1. Divide 8,75 entre 2,5 para recuperar el factor.
  2. 8,75 ÷ 2,5 = 3,5; 2,5 × 3,5 = 8,75.
Ver la respuesta

3,5

Errores frecuentes

Poner la coma contando solo las cifras de un factor.

Suma las cifras decimales de los dos factores antes de colocarla.

Tratar un factor desconocido como si se sumara al producto.

Despeja el factor mediante la operación inversa: divide el producto entre el factor conocido.

Preguntas para hacer

  • ¿Cuántas cifras decimales tienen juntos los factores?
  • ¿Qué división te permite hallar el factor que falta?

Consejo para practicar

La primera parte practica productos directos. En la segunda, se busca un factor ausente dividiendo; en la tercera, se juzga una igualdad y se corrige cuando el resultado propuesto no coincide. Una estimación aproximada antes del cálculo ayuda a valorar si el producto debe ser mayor o menor que los factores.
