Comparar números decimales

Ordenar números decimales comparando sus cifras por valor posicional.

En cada ejercicio se comparan dos números decimales con coma y se escribe >, < o =. La ficha combina respuesta directa, selección del signo y comprobación de una propuesta. Las cifras llegan hasta las milésimas. Para comparar, primero se observan las partes enteras; si coinciden, se continúa en orden por décimas, centésimas y milésimas, alineando las comas para no mezclar posiciones.

Antes de empezar

  • Leer números decimales con décimas, centésimas y milésimas.
  • Comprender el valor posicional de las cifras.
  • Usar correctamente los signos mayor, menor e igual.

Cómo resolverlo

  1. Escribir o imaginar los dos números con las comas alineadas.
  2. Comparar primero las partes enteras; el mayor determina el orden si son distintas.
  3. Si las partes enteras coinciden, comparar décimas y avanzar a centésimas y milésimas solo cuando sea necesario.
  4. Elegir el signo que conecta los números en el orden correcto.
  5. En la revisión, repetir la comparación de izquierda a derecha para confirmar o corregir el signo propuesto.

Ejemplo resuelto

Compara 2,408 y 2,481.

  1. Las unidades y las décimas coinciden: 2 y 4.
  2. En las centésimas, 0 es menor que 8; por tanto, el primer número es menor.
Ver la respuesta

2,408 < 2,481

Compara 1,735 y 1,729.

  1. Las unidades y décimas coinciden; en las centésimas, 3 es mayor que 2.
  2. La primera diferencia aparece ahí, así que el primer número es mayor.
Ver la respuesta

1,735 > 1,729

Errores frecuentes

Comparar las cifras decimales como si fueran números enteros sueltos.

Alinear las comas y atender al valor posicional de cada cifra.

Detenerse en una cifra que coincide e ignorar las siguientes.

Avanzar a la siguiente posición hasta encontrar la primera diferencia.

Preguntas para hacer

  • ¿Qué posición es la primera que cambia?
  • ¿Las partes enteras ya indican cuál número es mayor?

Consejo para practicar

Marcar con el dedo la primera cifra distinta ayuda a evitar que la última cifra llame más la atención que su valor real. En respuestas propuestas, leer el signo en voz alta como una afirmación completa.

Comparar números decimales

Comparar números decimales hasta las milésimas: fichas gratis para imprimir con soluciones. Usa mayor que, menor que o igual y comprueba tus respuestas.

Compara primero la parte entera. Si coincide, observa las décimas, las centésimas y después las milésimas. Tener más cifras decimales no significa ser mayor: 2,34 es mayor que 2,304. Puedes escribir 2,340 para alinear las posiciones sin cambiar su valor.

Las actividades incluyen escribir el signo correcto, elegir una respuesta y comprobar una propuesta. El símbolo > significa mayor que, el símbolo < significa menor que y = indica igualdad. Explica en qué posición encontraste la primera diferencia.
