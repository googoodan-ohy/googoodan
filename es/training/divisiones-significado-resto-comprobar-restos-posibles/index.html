Guía didáctica

Decide si es posible que haya resto.

Significado del resto

Elige los números posibles aplicando que el resto es mayor o igual que 0 y menor que el divisor.

Qué conviene repasar antes

  • Tablas de multiplicar
  • Restas y valor posicional

Cómo guiar el aprendizaje

  1. Comprueba el divisor y decide si cada opción es mayor o igual que 0 y menor que el divisor.
  2. Marca solo las opciones menores que el divisor.
  3. Comprueba que las opciones iguales o mayores que el divisor no pueden ser restos.
  4. Comprueba que 0 también puede ser un resto y vuelve a revisar si has marcado con un círculo todas las opciones que cumplen las condiciones.

Ejemplos resueltos

Al dividir entre 5, elige todos los números que pueden ser el resto: 0, 3, 5, 7.

  1. El resto debe ser mayor o igual que 0 y menor que el divisor, 5.
  2. 0 y 3 cumplen las condiciones. Con 5 y 7 se puede formar otro grupo.
Ver las respuestas de los ejemplos0, 3

Errores frecuentes y cómo ayudar

Elige como posibles restos números iguales o mayores que el divisor.

Si sobra una cantidad igual al divisor, se puede formar otro grupo. Por tanto, el resto siempre debe ser menor que el divisor.

No explica por qué ha elegido los números posibles.

En los dos primeros ejercicios, pídele que explique brevemente por qué elige o descarta cada opción.

Preguntas para comprobar la comprensión

  • Si sobra una cantidad igual al divisor, ¿se puede formar otro grupo?
  • En el ejemplo, ¿qué significa que 5−1 vale 4 para el mayor resto posible?
  • ¿Qué condición no cumple cada opción que no has elegido?

Uso de la ficha y revisión de los ejercicios

Comprueba primero si el niño o la niña puede explicar la respuesta del ejemplo: 0, 3. Asegúrate de que comprenda la condición de que el resto debe ser menor que el divisor. Pídele que indique por separado si cada opción cumple las condiciones. En los ejercicios en los que hay que elegir todas las opciones posibles, debe comprobarlas todas, incluso después de encontrar la primera respuesta correcta.

Siguientes ejercicios
